# VCC / ALCOM に追加

::: danger 現在は支援版をご購入いただいた方のみへの配布です
このリポジトリは、いまのところ**支援版をご購入いただいた方だけ**にご案内しています。

🔑 **解除キーが無いと、コンプリート版としてはご利用いただけません。**
導入しても**無料版（トライアル）として動作します**。

解除キーは、**支援版をご購入いただいた方がBOOTHの購入ページから入手できます**。

⚠️ **2.x をご購入済みの方も、3.0 では解除キーが必要です**（解除キーは 3.0 からの仕組みで、2.x には入っていません）→ [2.x をお使いの方へ](/guide/from-2x)

**一般公開の日程は、決まりしだいこのページと BOOTH でお知らせします。** 公開後は、どなたでもご利用いただけます。
:::

VCC / ALCOM から導入すると、アップデートのたびに unitypackage をインポートする必要がありません。Auto Fixプリセットもツールと一緒に更新されます。

<AgreeInstall />

::: details 自動で VCC / ALCOM が開かないときは
VCC / ALCOM の設定 →「Packages」→「Add Repository」に、次のURLを貼り付けてください。

```
https://lemoneru.github.io/vpm-repos/index.json
```

ご購入者は、商品に同梱されている「**VCCに追加**」ショートカットからでも同じことができます。
:::

## 追加したあと

1. リポジトリ「LEMONERU」を追加するか聞かれるので、**承認する**
2. プロジェクトのパッケージ管理で「**Avatar Blink Fix**」を探して、**＋ボタンで追加**する
   （検索欄に「blink」と入れると早いです）

   ![ALCOMのパッケージ管理画面。Avatar Blink Fix の行と追加ボタン](/images/alcom-add-package.png)

3. Unity でプロジェクトを開けば、もう使える状態です

そのまま[使い方](/guide/workflow)へどうぞ。**入れただけの状態が無料版**なので、購入前にお試しいただけます。

::: tip 新しいバージョンが出たときは
リポジトリを追加してあれば、VCC / ALCOM のプロジェクト画面に「**更新**」が出ます。押すだけで最新版になるので、ファイルを入れ直す必要はありません。
:::

## 有料版（コンプリート版）にする

有料版は [Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)で購入できます。

購入すると付いてくる**解除キーを、プロジェクトに1回インポートするだけ**で有料版になります。
**そのPCのすべてのプロジェクトで有料版になる**ので、プロジェクトごとの作業はいりません。

::: tip 2.x をご購入済みの方へ
**追加料金なしで 3.0 をお使いいただけます。**

⚠️ ただし **3.0 は「解除キー」方式に変わりました**（2.x は購入したファイルがそのまま製品版でした）。
コンプリート版としてお使いいただくには解除キーが必要です。**解除キーは BOOTH の購入ページからダウンロードしていただけます。**

→ [2.x をお使いの方へ（3.0 への移行）](/guide/from-2x)
:::

違いがよく分からないときは → [無料版と有料版の違い](/guide/editions)

## 補足

- 非破壊機能（[自動修正](/guide/auto-fix)・[ベイクモード](/guide/bake)）には **NDMF** が必要です
- VCC / ALCOM を使わない場合は [unitypackage での導入](/guide/install#unitypackage-で導入する)もできます
- くわしい手順は → [導入方法](/guide/install)
