# VCC / ALCOM に追加

Avatar Blink FixのVPMリポジトリを登録します。

::: danger 現在は支援版をご購入いただいた方のみへの配布です
コンプリート版として使うには、支援版のBOOTH購入ページで配布している3.0用の解除キーが必要です。2.xをご購入済みの方も、キーを入れるまでは無料版として動作します。

一般公開の日程は、決まりしだいこのページとBOOTHでお知らせします。
:::

<AgreeInstall />

開いたVCC / ALCOMで、リポジトリ「LEMONERU」の追加を承認してください。

::: details 自動で VCC / ALCOM が開かないときは
VCC / ALCOMのリポジトリ追加画面に、次のURLを貼り付けてください。

```
https://lemoneru.github.io/vpm-repos/index.json
```
:::

**登録できたら → [導入方法へ進む](/guide/install)**
