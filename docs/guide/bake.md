# ベイクモード

改変した表情を基礎メッシュへ焼き込む（ベイクする）モードです。
**表情アニメーションを使っていても崩れにくい**のが特長です。

このモードも非破壊です。焼き込みは**アップロード（ビルド）時に自動で行われ**、元のメッシュは書き換えません。

## いつ使う？

- [自動修正](/guide/auto-fix)で「**表情アニメーションとの競合**」を指摘されたとき
- 修正したのに、**ゲーム内で表情を動かすと目の動きがおかしい**とき
- **100 を超える値やマイナス値**（限界突破）を使った改変をしているとき

::: tip まず自動修正（通常モード）から
通常モードで問題がなければ、ベイクモードを使う必要はありません。競合の案内が出たときに切り替えるのが基本の流れです。
:::

## 手順

1. ヒエラルキーで**アバターを右クリック**
2. 「**Avatar Blink Fix**」→「**自動修正（ベイクモード）**」を選ぶ
3. そのまま**アップロード**すれば、焼き込みと修正が適用されています

すでに通常モードで設定済みの場合は、インスペクタの「**ベイクモードに切り替える**」ボタンからも切り替えられます。設定（チェック内容など）は引き継がれます。

※ ベイクモードは製品版の機能です（トライアル版では使えません）。

## ベイクされる範囲

既定では、**改変した BlendShape をすべて**ベイクします。ただし次のものは自動では含めません。

- MMD 対応の BlendShape
- 販売元の初期値のままになっている BlendShape

範囲を変えたいときは、インスペクタの「**ベイク範囲**」から変更できます。

## プレビューの注意

ベイクモードのプレビュー中は、**BlendShape のウェイトが 0 になります**（焼き込み後の状態を再現するためです）。

**表情改変の作業は「プレビューを終了」を押してから**行ってください。プレビュー中の値を見ながら改変すると、意図しない結果になります。

## フェイストラッキング（FT）アバターの場合

ベイクモードでは、FT 用の目閉じ BlendShape を検出すると**既定で修正に含めます**（通常モードとは逆です）。

FT 対応アバターの目閉じ調整は「アニメーションで改変後の BlendShape を打ち消す」方式が多く、メッシュに焼き込むとその打ち消しが効かなくなるためです。ベイクする場合は、こちら側で修正しておく必要があります。

不要な場合は、インスペクタの「フェイストラッキングの BlendShape」のトグルで外せます。

## 元に戻したいとき

[自動修正](/guide/auto-fix)と同じく、追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除するだけで元通りです。
