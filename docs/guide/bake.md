# ベイクモード（強化版）

**[自動修正](/guide/auto-fix)の強化版です。**
改変した表情をいったんメッシュに焼き込んで（ベイクして）から修正するので、**表情アニメーションを使っていても崩れにくく**なります。

このモードも非破壊です。焼き込みは**アップロード（ビルド）時に自動で行われ**、元のメッシュは書き換えません。

※ ベイクモードは有料版（コンプリート版）の機能です（無料版では使えません）。

→ どっちを使えばいい？ **[ベイクモードと通常モード、何が違うの？](/guide/bake-vs-normal)**

## いつ使う？

- [自動修正](/guide/auto-fix)で「**表情アニメーションとの競合**」と言われたとき
- 修正したのに、**ゲーム内で表情を動かすと目がおかしくなる**とき
- **100 を超える値やマイナス値**（限界突破）で改変しているとき

::: tip まずは自動修正（通常モード）から
通常モードで問題がなければ、ベイクモードにする必要はありません。競合の案内が出たら切り替える——それくらいの気持ちでOKです。
:::

## 手順

1. ヒエラルキーで**アバターを右クリック**
2. 「**Avatar Blink Fix**」→「**自動修正（ベイクモード）**」を選ぶ
3. あとは**アップロードするだけ**。焼き込みと修正が自動で反映されます

すでに通常モードで設定済みなら、インスペクタの「**ベイクモードに切り替える**」ボタンからでもOK。チェック内容などの設定はそのまま引き継がれます。

![ベイクモードのインスペクタ。検出数にベイク対象が加わり、ベイク範囲の切り替えが表示される](/images/easy-bake.png)

## ベイクされる範囲

はじめは、**改変した BlendShape をぜんぶ**ベイクする設定になっています。ただし次の2つは自動では入れません。

- MMD 対応の BlendShape
- 販売元の初期値のままになっている BlendShape

変えたいときは、インスペクタの「**ベイク範囲**」からどうぞ。

## プレビューの注意

ベイクモードでも、設定すると**プレビューが自動でONになります**。ただし通常モードと違い、プレビュー中は**BlendShape のウェイトが 0 になります**（焼き込み後の状態を再現しているためです）。

::: warning 表情改変は「プレビューを終了」してから
プレビュー中の値を見ながら改変すると、思っていたのと違う結果になってしまいます。
改変が終わったら「**表情を再読み込み**」を押して、変更後の状態で記録し直してください。
:::

## フェイストラッキング（FT）アバターの場合

ベイクモードでは、FT 用の目閉じ BlendShape を見つけると**はじめから修正に含めます**（通常モードとは逆です）。

FT 対応アバターの目閉じ調整は「アニメーションで改変後の BlendShape を打ち消す」方式が多く、メッシュに焼き込むとその打ち消しが効かなくなります。なのでベイクするなら、こちら側で直しておく必要があるわけです。

いらない場合は、インスペクタの「フェイストラッキングの BlendShape」のトグルで外せます。

## 元に戻したいとき

[自動修正](/guide/auto-fix)と同じく、追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除するだけで元通りです。
