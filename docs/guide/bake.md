# ベイクモード

改変した表情をいったんメッシュに焼き込んで（ベイクして）から修正するモードです。
表情アニメーションを使っていても崩れにくくなり、**限界突破（100を超える値・マイナス値）もそのまま再現できます**。

このモードも非破壊です。焼き込みはアップロード（ビルド）時に自動で行われ、元のメッシュは書き換えません。

※ ベイクモードは有料版（コンプリート版）の機能です（無料版では使えません）。

→ どっちを使えばいい？ [ベイクモードと通常モード、何が違うの？](/guide/bake-vs-normal)

## いつ使う？

- [自動修正](/guide/auto-fix)で「表情アニメーションとの競合」と表示され、ゲーム内で目がおかしくなるとき
- 100 を超える値やマイナス値（限界突破）で改変しているとき

::: tip まずは自動修正（通常モード）から
通常モードで問題がなければ、ベイクモードにする必要はありません。競合の案内が出た場合は、まずゲーム内で目の動きを確認してください。
:::

## 手順

1. ヒエラルキーでアバターを右クリック
2. 「**Avatar Blink Fix**」→「**自動修正（ベイクモード）**」を選ぶ
3. あとはアップロードするだけです。焼き込みと修正が自動で反映されます

すでに通常モードで設定済みなら、インスペクタの「**ベイクモードに切り替える**」ボタンからでもOK。チェック内容などの設定はそのまま引き継がれます。

![ベイクモードのインスペクタ。検出数にベイク対象が加わり、ベイク範囲の切り替えが表示される](/images/easy-bake.png)

## ベイクされる範囲

はじめは、改変した BlendShape をぜんぶベイクする設定になっています。ただし次の2つは自動では入れません。

- MMD 対応の BlendShape
- 販売元の初期値のままになっている BlendShape

変えたいときは、インスペクタの「**ベイク範囲**」からどうぞ。

### 名前の色で、外していいものが分かります

ベイク対象の一覧は、名前が2色に塗り分けられています。

- <span style="color:#22d3ee">■</span> **シアン＝目のまわり** … 修正に必要なので、そのままにしてください
- <span style="color:#f59e0b">■</span> **オレンジ＝目以外**（口まわりなど） … 外しても修正には影響しません

![ベイク対象BlendShapeの一覧。シアンの目まわりとオレンジの口・眉が混在している](/images/bake-legend.png)

はじめは改変ぶんをぜんぶ入れているので、オレンジが多めに付くのがふつうです。
そのままでも大きな問題は起きませんが、必要なものだけにしたいときはオレンジを外してください。

一覧は「**詳細設定**」→「**ベイク対象BlendShape**」から開けます。

## プレビューの注意

ベイクモードでも、設定するとプレビューが自動でONになります。ただし通常モードと違い、プレビュー中は**BlendShape のウェイトが 0 になります**（焼き込み後の状態を再現しているためです）。

プレビューOFFのときのボタン名は「**ベイク結果をプレビュー**」です。通常モードの「修正後をプレビュー」と名前が違いますが、押すものは同じです。

::: warning 表情改変は「プレビューを終了」してから
プレビュー中の値を見ながら改変すると、思っていたのと違う結果になってしまいます。
改変が終わったら「**表情を再読み込み**」を押して、変更後の状態で記録し直してください。
:::

## フェイストラッキング（FT）アバターの場合

ベイクモードでは、FT 用の目閉じ BlendShape を見つけると**はじめから修正に含めます**（通常モードとは逆です）。焼き込むと FT 側の打ち消しが効かなくなるためです。いらない場合は、インスペクタの「フェイストラッキングのBlendShape」で外せます。

→ [フェイストラッキングを使う方へ](/guide/face-tracking)

## 元に戻したいとき

[自動修正](/guide/auto-fix)と同じく、追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除するだけで元通りです。
