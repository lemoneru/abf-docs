# ベイクモードと通常モード、何が違うの？

Avatar Blink Fix には、通常モード、ベイクモード、手動修正があります。
どれを選ぶか、まずここで決められます。

| あなたの使い方 | まず選ぶもの | 理由 |
|---|---|---|
| 表情Animationを編集せず、元から入っているものをそのまま使う | **ベイクモード** | 0固定の項目をAnimationから削除せずに使えます |
| フェイストラッキングを使い、表情Animationを自分で調整しない | **ベイクモードを第一候補** | FT用BlendShapeをはじめから修正に含めます |
| FaceEmoなどで表情Animationも編集する | **通常モード** | 修正したBlendShapeの0固定カーブをAnimation側から削除して使います |
| 「自動修正（推奨）」が押せない／合うプリセットがない | **手動修正** | 目を変形させたBlendShapeを自分で選びます |

- **100を超える値やマイナス値で改変している場合は、ベイクモードが必要です。**
- **Avatar Mouth Fixと一緒に使う場合は、[メッシュ入れ替え式の通常修正](/guide/meshswap#avatar-mouth-fix-と併用する場合)を使います。**
- FTアドオン側がAnimationの0固定で補正している場合は通常モードが合うこともあります。くわしくは[フェイストラッキングを使う方へ](/guide/face-tracking)をご覧ください。

## ひとことで言うと

- **通常モード** … 目のBlendShapeだけを作り直します
- **ベイクモード** … 改変した表情をメッシュに焼き付けてから、目のBlendShapeを作り直します
- **手動修正** … 通常モードで直すBlendShapeを自分で選びます

改変後の顔を素の顔として焼き固めるので、あとから表情アニメーションが動いても土台がズレません。これがベイクモードがアニメーションに強い理由です。

## 比べるとこうなります

| | 通常モード | ベイクモード |
|---|---|---|
| 呼び出し方 | 右クリック →「自動修正（推奨）」 | 右クリック →「自動修正（ベイクモード）」 |
| 料金 | **無料版でも使えます** | **有料版（コンプリート版）のみ** |
| 表情アニメーションとの相性 | 競合すると目の動きが崩れることがあります | 破綻を軽減できる場合があります |
| 限界突破（100超・マイナス値） | 再現できません | **ベイクでのみ再現できます** |
| フェイストラッキング用BlendShape | はじめは含めません | はじめから含めます |
| プレビュー中の見え方 | 修正後の顔 | BlendShapeが0の状態 |
| 元のアバター | 書き換えません | 書き換えません |
| 元に戻す | オブジェクトを削除するだけ | 同じ |

どちらも非破壊です。焼き付けはアップロード（ビルド）のときに行われるので、シーンのメッシュはそのままです。

::: details フェイストラッキングの扱いが逆なのはなぜ？
FT対応アバターの目閉じ調整は、アニメーションで改変後のBlendShapeを0にする方式が多く、ベイクするとその0化が空振りしてしまいます。通常モードではFT側の仕組みがそのまま働くので、はじめは含めません。どちらもインスペクタで変えられます。

→ [フェイストラッキングを使う方へ](/guide/face-tracking)
:::

## ベイクモードの弱いところ

そのぶん、通常モードより気をつける点が2つあります。

### 1. 焼き付ける範囲は広めです

はじめは、改変したBlendShapeをぜんぶ焼き付ける設定になっています。
そのため、目とは関係ない部分（口まわりなど）まで一緒に焼き付くことがあります。

そのままでも大きな問題は起きませんが、必要なものだけにしたいときは、インスペクタの「**ベイク範囲**」から外せます。

なお、次の2つは自動では焼き付けません。

- MMD対応のBlendShape
- 販売元の初期値のままになっているBlendShape

### 2. プレビュー中は表情が0になります

ベイクモードのプレビューは、焼き付けたあとの状態を再現しています。
そのため、プレビュー中は**BlendShapeのウェイトが0**になり、シーン上のアバターは素の顔に見えます。

::: warning 表情改変をやり直すときは、先にプレビューを終了してください
0になった状態のまま値をいじると、思っていたのと違う結果になります。
手順は通常モードと同じです → [自動修正: あとから表情改変をやり直すとき](/guide/auto-fix#あとから表情改変をやり直すとき)
:::

## あとからでも切り替えられます

通常モードで設定したあとでも、インスペクタの「**ベイクモードに切り替える**」ボタンで移れます。
チェック内容などの設定は引き継がれるので、やり直しにはなりません。

「表情アニメーションとの競合」を見つけたときは、この案内とボタンが自動で出ます。

手順はこちらへどうぞ。

- [自動修正（推奨）](/guide/auto-fix) … 通常モード
- [ベイクモード](/guide/bake)
- [手動修正](/guide/manual-fix)
- [実際の修正の流れ](/guide/workflow) … 表情改変からゲーム内で確認するまでの通し
