# ベイクモードと通常モードの違い

通常モードは、改変した表情に合わせて目を閉じるBlendShapeを修正します。<br>
ベイクモードは、改変後の形をメッシュに焼き込んでから修正します。

## どちらを使えばいい？

<div class="usage-branch">

### 表情アニメーションも自分で編集する場合

[通常モードの自動修正](/guide/auto-fix)をお使いください。<br>
無料版でも、普段のまばたきに使うBlendShapeを1つ修正できます。

既存の表情アニメーションを流用するときの注意は、[実際の修正の流れ](/guide/workflow)にまとめています。

</div>

<div class="usage-branch">

### アバター標準の表情アニメーションを使う場合

表情アニメーションを編集せずに使う場合は、[ベイクモード](/guide/bake)がおすすめです。<br>
通常モードでゲーム内の目の形が崩れる場合も、ベイクモードで軽減できる可能性があります。

※ ベイクモードはコンプリート版の機能です。100を超える値やマイナス値で改変している場合も、ベイクモードをご利用ください。

</div>

通常モードで問題なく使えている場合は、切り替える必要はありません。

## 修正内容の違い

| | 通常モード | ベイクモード |
|---|---|---|
| 表情の扱い | 改変したBlendShapeの値を使います | 改変した形を、値0の形として焼き込みます |
| 表情アニメーション | 設定によって競合することがあります | 競合による破綻を軽減できる可能性があります |
| 限界突破（100超・マイナス値） | 再現できません | 再現できます |
| FT用BlendShapeの初期設定 | 修正に含めません | 修正に含めます |
| プレビュー | 修正後の表情を表示します | 焼き込んだBlendShapeは値0になり、改変後の表情を表示します |

どちらも元のメッシュは書き換えません。<br>
追加されたAvatar Blink Fixのオブジェクトを削除すると、修正前に戻せます。

## 切り替え方

通常モードのインスペクターで［ベイクモードに切り替える］を押してください。<br>
チェック内容などの設定を引き継いで切り替わります。

ベイクモードでは、目以外の改変もベイクする場合があります。<br>
切り替えたあとに［ベイク範囲］を確認してください。

## ほかのツールや改変と一緒に使う場合

- **フェイストラッキング**：表情アニメーションを自分で調整しない場合は、ベイクモードをお試しください。FTアドオンがアニメーションの0固定で補正している場合は、通常モードが合うこともあります。詳しくは[フェイストラッキングの設定](/guide/face-tracking)をご確認ください。
- **Avatar Mouth Fix**：[メッシュ入れ替え式の通常修正](/guide/meshswap#avatar-mouth-fix-と併用する場合)をご利用ください。非破壊方式やベイク修正との併用には対応していません。

［自動修正（推奨）］が押せないアバターは、[手動修正](/guide/manual-fix)で必要項目を選んで修正できます。
