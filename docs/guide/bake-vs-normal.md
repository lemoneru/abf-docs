# ベイクモードと通常モード、何が違うの？

Avatar Blink Fix の修正には、**通常モード**と**ベイクモード**（強化版）の2つがあります。
「どっちを使えばいいの？」から先に答えます。

::: tip 迷ったときの答え
**まずは通常モード**（右クリック →「自動修正（推奨）」）。これで直れば、それで終わりです。

**表情アニメーションを使っているなら、はじめからベイクモード**のほうが崩れにくいです。
:::

## ひとことで言うと

- **通常モード** … 目のBlendShapeだけを作り直します
- **ベイクモード** … **改変した表情をメッシュに焼き付けてから**、目のBlendShapeを作り直します

改変後の顔を「素の顔」として焼き固めてしまうので、あとから表情アニメーションが動いても土台がズレません。これがベイクモードが**アニメーションに強い**理由です。

## 比べるとこうなります

| | 通常モード | ベイクモード（強化版） |
|---|---|---|
| 呼び出し方 | 右クリック →「自動修正（推奨）」 | 右クリック →「自動修正（ベイクモード）」 |
| 料金 | **無料版でも使えます** | **有料版（コンプリート版）のみ** |
| 表情アニメーションとの相性 | 競合すると目の動きが崩れることがあります | **崩れにくいです** |
| 限界突破（100超・マイナス値） | 再現できません | **ベイクでのみ再現できます** |
| フェイストラッキング用BlendShape | はじめは含めません | はじめから含めます |
| プレビュー中の見え方 | 修正後の顔 | BlendShapeが0の状態 |
| 元のアバター | 書き換えません | 書き換えません |
| 元に戻す | オブジェクトを削除するだけ | 同じ |

どちらも**非破壊**です。焼き付けはアップロード（ビルド）のときに行われるので、シーンのメッシュはそのままです。

::: details フェイストラッキングの扱いが逆なのはなぜ？
FT対応アバターの目閉じ調整は「アニメーションで改変後のBlendShapeを0にする」方式が多く、ベイクするとその0化が空振りしてしまいます。なのでベイクモードでは、こちら側で直しておく必要があるわけです。

通常モードではFT側の仕組みがそのまま働くので、はじめは含めません。どちらもインスペクタのトグルで変えられます。
:::

## ベイクモードの弱いところ

強化版とはいえ、通常モードより気をつける点が2つあります。

### 1. 焼き付ける範囲は広めです

はじめは、**改変したBlendShapeをぜんぶ**焼き付ける設定になっています。
そのため、**目とは関係ない部分（口まわりなど）まで一緒に焼き付く**ことがあります。

**そのままでも大きな問題は起きません**が、必要なものだけにしたいときは、インスペクタの「**ベイク範囲**」から外せます。

なお、次の2つは自動では焼き付けません。

- MMD対応のBlendShape
- 販売元の初期値のままになっているBlendShape

### 2. プレビュー中は表情が0になります

ベイクモードのプレビューは、**焼き付けたあとの状態**を再現しています。
そのため、プレビュー中は**BlendShapeのウェイトが0**になり、シーン上のアバターは素の顔に見えます。

::: warning 表情改変をやり直すときは、先にプレビューを終了してください
0になった状態のまま値をいじると、思っていたのと違う結果になります。

1. インスペクタの「**プレビューを終了**」を押す
2. 表情改変をやり直す
3. 「**表情を再読み込み**」を押して、改変後の状態で覚え直させる
:::

## あとからでも切り替えられます

通常モードで設定したあとでも、インスペクタの「**ベイクモードに切り替える**」ボタンで移れます。
チェック内容などの設定はそのまま引き継がれるので、やり直しにはなりません。

「表情アニメーションとの競合」を見つけたときは、この案内とボタンが自動で出ます。

## まとめ

- **通常モードで問題がなければ、それでOK。** 無料版でも使えます
- **表情アニメーションを使っている／「競合」と言われた／限界突破で改変している** なら、ベイクモード
- ベイクモードは**焼き付ける範囲が広め**で、**プレビュー中は表情が0**になります。この2つだけ覚えておけば大丈夫です
