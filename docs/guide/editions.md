# 無料版と有料版の違い

主な違いは、修正できるBlendShapeの数と、使える便利機能です。

無料版でも修正できます。まずはご自身の表情改変で使えるかお試しください。あとから簡単に[コンプリート版（有料版）へアップグレード](/guide/unlock-key)できます。

## 無料版でできること

Avatar Blink Fixをインストールすると、そのまま無料版として使えます。
通常のまばたきに使われるBlendShape `vrc.blink` を修正できます。

→ [導入方法](/guide/install) ／ [自動修正の手順](/guide/auto-fix)

## 有料版でできること

次のような場合は、有料版で対応できます。

- MMD用のBlendShapeも直したい
- フェイストラッキング用の目閉じBlendShapeも直したい
- ウィンクや笑い目など、目を閉じるBlendShapeをまとめて直したい
- 表情アニメーションと競合していて、[ベイクモード](/guide/bake)を使いたい
- 微調整モードを使いたい、[まばたきと表情アニメーションを合成](/guide/animation)したい（おまけ機能）

※ Auto Fixプリセットは **100体以上**のアバターに対応しています（今も増え続けています）。
対応アバターの一覧は [Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)でご確認いただけます。

::: tip 無料版で対象が見つからないアバターもあります
無料版が自動で選ぶのは、よく使われるまばたきBlendShapeの名前（`vrc.blink` や `eye_close` など）です。アバターによってはその名前のBlendShapeが無く、無料版では対象を見つけられないことがあります。
その場合でも、有料版なら任意のBlendShapeを修正できます（対応アバターならプリセットが自動で選んでくれます）。
:::

## 有料版は必要ですか？

まずは無料版のまま使ってみてください。
修正後、ゲーム内で問題がなければ、**アップグレードの必要はありません**。

まだ購入していない方は、もっと直したくなったときに[Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)から購入できます。

購入済みの方は、BOOTHから解除キーをダウンロードし、プロジェクトに1回インポートしてください。くわしい操作は[コンプリート版へのアップグレード](/guide/unlock-key)にまとめています。
解除キーを1回入れると、そのPCのすべてのプロジェクトで有料版になります。

- ツールを入れ直したり、プロジェクトを作り直したりする必要はありません
- アップデートしても、入れ直しは不要です

2.x をご購入済みの方は、追加料金なしでそのまま 3.0 を使えます → [3.0 へのアップデート方法](/guide/from-2x)
