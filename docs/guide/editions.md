# 無料版と有料版の違い

主な違いは、修正できるBlendShapeの数と、使える便利機能です。

無料版でも修正できます。まずはご自身の表情改変で使えるかお試しください。<br>
あとから簡単にコンプリート版（有料版）へアップグレードできます。

## 無料版でできること

Avatar Blink Fixをインストールすると、そのまま無料版として使えます。
通常のまばたきに使われるBlendShape `vrc.blink` を修正できます。

## 有料版でできること

次のような場合は、有料版で対応できます。

- ウィンクや笑い目など、目を閉じるBlendShapeをまとめて直したい
- MMD用のBlendShapeも直したい
- フェイストラッキング用の目閉じBlendShapeも直したい
- 表情アニメーションと競合していて、[自動修正（ベイクモード）](/guide/bake)を使いたい
- うるうるするまばたきなどのアニメーションを、表情が崩れないように表情アニメーションと合成したい → [Animation対応（おまけ機能）](/guide/animation)
- 微調整モードを使いたい（おまけ機能）

※ Auto Fixプリセットは **100体以上**のアバターに対応しています（今も増え続けています）。
対応アバターの一覧は [Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)でご確認いただけます。

::: tip 無料版で修正できないアバターもあります
無料版で修正できるのは、`vrc.blink` や `eye_close` などのBlendShapeです。アバターによってはその名前のBlendShapeがなく、修正できない場合があります。
その場合でも、有料版なら任意の目を閉じるBlendShapeを修正できます。
:::

## 有料版は必要ですか？

まずは無料版をお試しください。
1つのBlendShapeの修正だけで不都合なく使えるなら、アップグレードの必要はありません。

その他の目を閉じるBlendShapeや、MMD用・フェイストラッキング用のBlendShapeも修正したくなったら、[Avatar Blink Fixの販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)で解除キーを購入して、簡単にアップグレードできます。

※ 解除キーは1回インポートすると、そのPCのすべてのプロジェクトで有料版として使えます。別のPCで使う場合は、そのPCでも1回インポートしてください。

2.x をご購入済みの方は、追加料金なしでそのまま 3.0 を使えます → [3.0 へのアップデート方法](/guide/from-2x)
