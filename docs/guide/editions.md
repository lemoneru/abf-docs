# 無料版と有料版の違い

Avatar Blink Fix は、**入れただけの状態が無料版**です。買う前に、自分のアバターで動くかどうかそのまま試せます。

## まずは無料版でどうぞ

無料版でできるのは、**VRChatで使われるまばたきのBlendShapeを、自動で正しい形へ修正すること**です。

表情を改変したらまばたきで目が突き抜ける・閉じきらない——という症状は、たいていこれで直ります。
**まばたきさえ直ればいい**という場合は、無料版のまま使い続けてもらって問題ありません。

→ [導入方法](/guide/install) ／ [自動修正の手順](/guide/auto-fix)

## 有料版でできるようになること

無料版で直せるのは、自動で選ばれた**まばたき用のBlendShape 1つ**です。
次のようなことをしたくなったら、有料版の出番です。

- **MMD用のBlendShapeも直したい**
- **フェイストラッキング用の目閉じBlendShapeも直したい**
- ウィンクや笑い目など、**目を閉じるBlendShapeをまとめて直したい**
- 表情アニメーションと競合していて、[ベイクモード](/guide/bake)を使いたい
- まばたきAnimationの合成や、微調整モードを使いたい

## 比較表

| | 無料版 | 有料版 |
|---|:---:|:---:|
| 修正できるBlendShape | 自動で選ばれた**まばたき用の1つ** | **制限なし**（好きなだけ選べます） |
| 右クリックからの自動修正 | ✅ | ✅ |
| 修正後のプレビュー・元に戻す | ✅ | ✅ |
| Auto Fixプリセット（133体同梱） | ✅ | ✅ |
| メッシュ入れ替え式（従来の窓） | ✅ | ✅ |
| MMD用BlendShapeの修正 | — | ✅ |
| フェイストラッキング用BlendShapeの修正 | — | ✅ |
| [ベイクモード](/guide/bake) | — | ✅ |
| まばたきAnimation合成 | — | ✅ |
| 微調整モード・設定の書き出し／読み込み | — | ✅ |

::: tip 無料版で対象が見つからないアバターもあります
無料版が自動で選ぶのは、よく使われるまばたきBlendShapeの名前（`vrc.blink` や「まばたき」など）です。アバターによってはその名前のBlendShapeが無く、無料版では対象を見つけられないことがあります。その場合は有料版で好きなBlendShapeを指定してください。
:::

## どちらをインポートすればいい？

**導入するファイルは同じ1つだけ**です。無料版と有料版でパッケージが分かれているわけではありません。

1. [導入方法](/guide/install)のとおりツールを入れる → **この時点で無料版として動きます**
2. 購入した方は、**同梱のファイル（解除キー）を1回インポート** → それだけで有料版になります

- プロジェクトを作り直したり、ツールを入れ直したりする必要はありません
- **同じPCなら、ほかのプロジェクトでもそのまま有料版として使えます**
- アップデートしても、入れ直しは不要です

## 無料版で設定したあと、有料版にしたら

無料版のときに作った設定は、**修正対象が1つだけ**の状態で保存されています。
有料版にしたら、インスペクタの「**表情を再読み込み**」を押してください。**すべてのBlendShapeを対象に設定し直します。**

（ツール側にも同じ案内が出ます。押し忘れても壊れることはありません）
