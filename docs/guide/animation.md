# まばたきと表情アニメーションの合成（おまけ機能）

うるうるするまばたきなど、好きなまばたきアニメーションを表情に合成できます。<br>
表情に合わせたBlendShapeと、新しいアニメーションファイルを書き出す機能です。

※ コンプリート版のおまけ機能です。通常のまばたき修正だけであれば、この操作は必要ありません。

## ① 合成するアニメーションを用意する

表情改変とまばたきの修正を済ませてから、次のアニメーションを用意してください。

- 合成先の表情アニメーション
- 合成したいまばたきアニメーション

まばたきアニメーション自体を自動で作る機能ではないため、使いたいものを用意する必要があります。

## ② Animation対応を開く

Avatar Blink Fixのインスペクターで、［詳細設定］→［Animation対応］を開いてください。<br>
メッシュ入れ替え式では、ウィンドウの［⑥ まばたきAnimation合成］から設定できます。

<div class="usage-branch">

### 表情アニメーション

［表情Animation設定］の枠に、表情アニメーションの `.anim` ファイルをドラッグ＆ドロップしてください。<br>
複数のファイルをまとめて入れられます。

［合成先BlendShape］では、まばたきを合成する先を選びます。

</div>

<div class="usage-branch">

### まばたきアニメーション

［まばたきAnimation設定］の［まばたきAnimation］に、使いたい `.anim` ファイルを入れてください。<br>
［まばたきBlendShape］で、そのアニメーション内のまばたきに使うBlendShapeを選びます。

</div>

## ③ 合成モードを確認する

「同じBlendShapeが利用されています」と表示された場合は、［合成モード］を選んでください。

| 合成モード | 動き方 |
|---|---|
| 表情優先 | 笑い目などの表情の形を優先します |
| まばたき優先 | 表情中も、まばたきの動きを優先します |

まずは［表情優先］で確認してください。<br>
表情中にもまばたきを入れたい場合は、［まばたき優先］に変えて見比べてください。

## ④ アニメーションを生成する

［Animation用BlendShape/Animation生成］を押してください。<br>
元の表情アニメーションは上書きせず、新しいファイルが作成されます。PhysBoneやオブジェクトのON/OFFなど、BlendShape以外のキーも引き継がれます。

生成先は、次のフォルダです。

```text
Assets/LEMONERU/Avatar Blink Fix/Animation/<アバター名>/<日時>/
```

ファイル名は、元のアニメーション名に `_ABF_Blink` を付けたものになります。

::: details ［2回目以降は上書きする］について
通常は生成するたびに、日時の付いたフォルダが作成されます。<br>
チェックを入れると、前回と同じ場所に生成済みファイルを上書きします。
:::

## ⑤ 生成したアニメーションに差し替える

FaceEmoなどの表情設定ツールで、元のアニメーションを、生成した `_ABF_Blink` のファイルに差し替えてください。<br>
アバターの設定は自動では変更されないため、この差し替えが必要です。

::: warning 表情設定ツール側のまばたき設定
まばたきを有効にするオプションがある場合は、OFFにしてください。<br>
生成したアニメーションにはまばたきが含まれているため、二重に動いてしまうことがあります。
:::

差し替えたらアップロードし、VRChatで表情を切り替えながら、まばたきの動きを確認してください。

## うまく動かないときは

| 症状 | 確認するところ |
|---|---|
| ファイルを設定欄に入れられない | Projectウィンドウから `.anim` ファイルを選んでください |
| 生成ボタンが押せない | 表情アニメーション、またはまばたきアニメーションと［まばたきBlendShape］が設定されているか確認してください |
| ゲーム内で動きが変わらない | ⑤のアニメーション差し替えを確認してください |
| まばたきが速い／二重に見える | 表情設定ツール側のまばたきオプションを確認してください |
| 表情が崩れる | 合成モードを変更して、生成し直してください |

生成後に顔のBlendShapeを改変し直した場合は、まばたき修正の設定を更新してから、アニメーションを生成し直してください。<br>
新しく生成したファイルへの差し替えも必要です。

解決しない場合は、[お問い合わせ](/faq#contact)ください。
