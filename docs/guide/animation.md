# まばたきと表情アニメーションの合成（おまけ機能）

作ってある表情アニメーションに、まばたきを混ぜた新しいアニメーションを書き出します。

::: tip 使いたい方だけどうぞ
**まばたきを直すだけなら、この機能は使いません。** [自動修正](/guide/auto-fix)だけで完結します。

このページは「表情を切り替えているあいだも、まばたきさせたい」という方向けのおまけです。
手順は多めなので、必要になったときだけ読んでください。
:::

※ 有料版（コンプリート版）の機能です。

## こんなときに使います

> 表情アニメーションはひととおり作ってある。
> そこへ、好きなまばたきを全部の表情に入れたい。

表情アニメーションを1つずつ開いて、まばたきのキーを手で足していくのは大変です。そこをまとめて作ります。

::: warning よくある誤解
**まばたきのアニメーションを自動で作ってくれる機能ではありません。**
すでにある表情アニメーションと、すでにあるまばたきアニメーション。この2つを材料にします。
:::

## どういう仕組みなのか

先に中身を書いておきます。ここが分かると、あとの手順で迷いません。

1. 顔のメッシュに、**まばたきと表情を合わせた新しい BlendShape** を追加します
2. その BlendShape を動かす、**新しいアニメーションファイル**を書き出します
3. 元の表情アニメーションは**そのまま残ります**。上書きはしません

つまり、**アバターの設定が自動で書き変わるわけではありません。** 材料が新しく作られるだけです。
できたアニメーションを自分で使う場所へ入れて、はじめて反映されます。

## 手順

> ① 表情改変を終わらせる → ② まばたき修正を設定する → ③ 表情アニメーションを入れる → ④ まばたきアニメーションを指定する → ⑤ 生成する → ⑥ できたアニメーションに差し替える

::: danger ⑤まで進んだあとに表情改変をやり直すと、作り直しになります
生成したあとで顔の BlendShape をいじると、作ったアニメーションが合わなくなります。
表情改変は①で終わらせてください。
:::

### ① 表情改変を終わらせる

いつもどおり、顔の BlendShape で表情を作り込んでください。
この機能は、ここで作った顔を土台にします。

### ② まばたき修正を設定する

アバターを右クリック →「Avatar Blink Fix」→「**自動修正（推奨）**」。
先にまばたきの修正を入れておきます（→ [自動修正](/guide/auto-fix)）。

### ③ 表情アニメーションを入れる

インスペクタの「**詳細設定**」を開き、いちばん下の「**Animation対応**」を開きます。

「**表情Animation設定**」の枠に、今使っている表情アニメーションをドラッグ＆ドロップしてください。
複数まとめて入れられます。

::: tip 入らないときは
枠の上でカーソルが変わらない場合は、AnimationClip 以外を掴んでいます。
プロジェクトウィンドウから、`.anim` ファイルを直接ドラッグしてください。
:::

その下の「**合成先BlendShape**」は、まばたきを混ぜる先です。ふつうは表示されているままで大丈夫です。

### ④ まばたきアニメーションを指定する

「**まばたきAnimation設定**」の「**まばたきAnimation**」に、使いたいまばたきの `.anim` を入れます。

続いて「**まばたきBlendShape**」で、そのアニメーションのどの BlendShape をまばたきとして扱うかを選びます。
候補は自動で絞られるので、出てきたものから選べば大丈夫です。

#### 「同じBlendShapeが利用されています」と出たとき

表情側とまばたき側が、同じ BlendShape を取り合っているという案内です。
このときだけ「**合成モード**」が出てきます。

| | どうなるか |
|---|---|
| 表情優先 | 表情の形が優先されます。笑い目などの表情中は、その形のまま保たれます |
| まばたき優先 | まばたきが優先されます。どの表情でも、まばたきの動きが入ります |

迷ったら「表情優先」から試してください。作った表情の見た目がそのまま残るほうを基準にします。
表情中にもまばたきしてほしければ「まばたき優先」に変えて、両方見比べるのがいちばん早いです。

### ⑤ 生成する

「**Animation用BlendShape/Animation生成**」を押します。

::: tip 「2回目以降は上書きする」のチェック
初回は付けなくて大丈夫です。

押すたびに日時つきのフォルダが増えていくので、同じ設定で作り直すことが分かっているときにチェックを入れると、前回と同じ場所へ上書きされます。
:::

**できたものはここに出ます。**

```
Assets/LEMONERU/Avatar Blink Fix/Animation/<アバター名>/<日時>/
```

アバター名のフォルダの下に、押した日時のフォルダが作られます。
ファイル名は「**元のアニメーション名 + `_ABF_Blink`**」です。

「Animation生成完了」と出たら、このフォルダを開いて中身を確認してください。

### ⑥ できたアニメーションに差し替える

🔴 **ここを忘れると、何も変わりません。**

お使いの表情設定ツールで、**元のアニメーションを、生成された `_ABF_Blink` のほうに差し替えてください。**
差し替えて初めて、ゲーム内でまばたきが入ります。

::: warning 表情設定ツール側の「まばたき」オプションは外してください
お使いの表情設定ツールに、**まばたきを有効にする設定がある場合は外します。**

生成したアニメーションには、もうまばたきが入っています。
ツール側でもまばたきを足すと、二重にかかって目の動きが崩れます。
:::

## 直ったか確かめる

アップロードして、VRChat で表情を切り替えながらまばたきを見てください。

- 表情を変えてもまばたきする → 成功です
- 何も変わらない → ⑥の差し替えが済んでいないことがほとんどです
- まばたきが不自然に速い・二重に見える → 表情設定ツール側のまばたきオプションが残っています
- 表情が崩れる → ④の合成モードを、もう一方に変えて生成し直してください

## うまくいかないときは

- 生成ボタンが押せない … 表情Animationとまばたきアニメーションが、どちらも入っていない状態です。どちらか一方でも入れれば押せます
- どこに出たか分からない … 上のパスを見てください。日時のフォルダなので、いちばん新しいものが今回のぶんです
- 表情を作り直した … お手数ですが、③からやり直してください。生成済みのアニメーションは、新しい顔とは合いません

解決しないときは [BOOTH](https://lemoneru.booth.pm/items/7074770) のメッセージからご連絡ください。
