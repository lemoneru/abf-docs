# BlendShapeを追加する改変と一緒に使うとき

BlendShapeを追加・変更する改変は、Avatar Blink Fixで修正する前に済ませてください。<br>
そのあとで[自動修正](/guide/auto-fix)を行います。

## 修正したあとでBlendShapeを追加した場合

1. Avatar Blink Fixのインスペクターで［プレビューを終了］を押す
2. BlendShapeの追加・変更を行う
3. ［表情を再読み込み］を押す

BlendShapeを削除した場合も、同じように読み込み直してください。

::: warning メッシュ入れ替え式を使っている場合
［修正前に戻す］で元のメッシュに戻してから、追加・変更を行ってください。<br>
修正済みのメッシュにそのまま追加すると、修正の記録に追加分が反映されないことがあります。

すでに追加してしまった場合は、[BlendShapeを追加したときの対処](/faq#added-shapes)をご確認ください。
:::

## こんなときは

<div class="usage-branch">

### 自動修正がグレーで押せない

BlendShapeの構成が変わると、プリセットが合わなくなることがあります。<br>
ツールとプリセットを最新版に更新してください。

それでも押せない場合は、[手動修正](/guide/manual-fix)で必要項目を選んで修正できます。

</div>

<div class="usage-branch">

### 顔のメッシュが見つからない／別のメッシュが選ばれる

インスペクターの［顔のメッシュ（自動選択）］の横で、［手動設定］にチェックを入れてください。<br>
顔のメッシュを直接指定できます。

詳しくは[顔のメッシュを手動で指定する方法](/faq#face-not-found)をご確認ください。

</div>
