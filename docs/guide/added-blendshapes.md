# BlendShape を追加する改変と一緒に使うとき

表情を足したり、パーツを足したりして **BlendShape を増やす改変**をしたアバターでも、Avatar Blink Fix はそのまま使えます。

**気をつけることは、順番だけです。**

## 順番

1. **BlendShape の追加・変更を先に済ませる**
2. そのあとで [自動修正（推奨）](/guide/auto-fix)を使う

これだけです。ツールは**そのときのアバターの状態を見て**設定を作るので、先に追加を済ませておけば手戻りがありません。

## あとから BlendShape の構成が変わったとき

すでに修正してあるアバターに、あとから BlendShape を足した・減らした場合は、**覚え直させてください。**

インスペクタの「**表情を再読み込み**」を押すだけです。

→ 手順は [自動修正: あとから表情改変をやり直すとき](/guide/auto-fix#あとから表情改変をやり直すとき)

## 「自動修正（推奨）」がグレーで押せなくなったとき

BlendShape が増減すると、そのアバター用の Auto Fix プリセットが合わなくなることがあります。

1. まず**ツールを最新版に更新**してみてください（対応済みのプリセットが入っていることがあります）
2. それでも押せないときは [手動修正](/guide/manual-fix)で、直したい BlendShape を自分で選べます

→ [アバターをアップデートしたら、Auto Fix が出なくなった](/faq#avatar-updated)

## 顔のメッシュが変わった／増えた場合

複数のアバターを組み合わせた改変などで、顔のメッシュが自動で選ばれない・別のメッシュが選ばれることがあります。

インスペクタの「顔のメッシュ（自動選択）」の横の「**手動設定**」にチェックを入れて、顔のメッシュを直接指定してください。

→ [顔のメッシュが自動で見つからない／別のメッシュが選ばれる](/faq#face-not-found)

::: tip 非破壊のほうが相性がよいです
[自動修正](/guide/auto-fix)や[ベイクモード](/guide/bake)はメッシュを差し替えないので、あとから BlendShape が増えても「表情を再読み込み」だけで済みます。

[メッシュ入れ替え式](/guide/meshswap)では、修正の記録が**最初に修正したときのメッシュ**を指したままになり、追加分が反映されないことがあります。手順は [FAQ](/faq#added-shapes) をご覧ください。
:::
