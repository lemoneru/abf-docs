# メッシュ入れ替え式（従来方式）

修正済みのメッシュを作って、その場でアバターのメッシュを差し替える方式です。2.x と同じ操作感で使えます。

**「修正前に戻す」ボタンでいつでも元に戻せます。**

## いつ使う？

- **NDMF を入れていない**環境で使いたいとき
- 他のツールと相性が出て、[自動修正（非破壊）](/guide/auto-fix)がうまく動かないとき
- 2.x と同じ手順で作業したいとき
- **Avatar Mouth Fix と併用する**とき（→ [下記](#avatar-mouth-fix-と併用する場合)）

::: tip ふだんは右クリックの自動修正で十分です
この方式はメッシュを実際に差し替えるので、修正後に表情改変をやり直すときは一度戻す手間があります。特別な事情がなければ[自動修正（推奨）](/guide/auto-fix)のほうが楽です。
:::

## 手順

1. メニューの「**Tools**」→「**Avatar Blink Fix**」でウィンドウを開く
2. 「**メッシュ入れ替え式（旧式）**」タブを選ぶ
3. **① アバターPrefab** に、ヒエラルキーのアバターをドラッグ＆ドロップ
4. 対応アバターなら、プリセット欄でアバターを選んで「**Auto Fix（自動修正）**」を押すだけで完了！
5. 非対応アバターは、**③ 目を変形させている BlendShape** と **④ 修正対象の BlendShape** を確認・チェックして、修正を実行

![メッシュ入れ替え式タブ。アバターと顔メッシュがセットされ、Auto Fix ボタンが押せる状態](/images/meshswap-window.png)

修正が終わると、顔のメッシュが修正済みのものに差し替わります。そのままアップロードしてください。

## 修正前に戻す

ウィンドウの「**修正前に戻す**」ボタンで、元のメッシュに戻せます。

- 表情改変をやり直したいときは、いったん戻す → 改変する → もう一度修正、の順で
- 修正の記録はアバター名ごとに保存されています。アバターを複製したり名前を変えたりすると記録と合わなくなり、二重修正防止の案内が出ることがあります（→ [FAQ](/faq#copied-avatar)）

## ベイク修正

メッシュ入れ替え式にもベイク修正があります。改変した表情をメッシュに焼き込んでから修正する方式で、表情アニメーションを使っていても崩れにくくなります。

※ Avatar Mouth Fix と併用するときは、ベイク修正ではなく通常修正を使ってください。

## オプション機能

### ⑤ 微調整モード

修正結果を BlendShape ごとに細かく調整できます。調整した設定は JSON に書き出し／読み込みできるので、Blender などで作り直したアバターにも同じ設定を持っていけます。

### ⑥ まばたき Animation 合成

まばたきと表情の Animation を合成します。PhysBone やオブジェクトの ON/OFF など、BlendShape 以外のキーも消えずに引き継がれます。

## Avatar Mouth Fix と併用する場合

今のバージョンで併用できるのは、**「メッシュ入れ替え式の通常修正」→「Avatar Mouth Fix」の順番だけ**です。

非破壊（右クリック）修正・ベイク修正との併用は、今後のアップデートで対応予定です。対応外の組み合わせを選ぶと、ツール内に案内が出るようになっています。
