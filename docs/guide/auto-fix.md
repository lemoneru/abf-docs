# 自動修正（推奨）

いちばん簡単な使い方です。まずはこれをどうぞ。

表情改変からアップロードまでの通しの流れは → [実際の修正の流れ](/guide/workflow)

## 手順

1. **ヒエラルキーのアバターを右クリック**
2. 「**Avatar Blink Fix**」→「**自動修正（推奨）**」を選ぶ

   ![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

3. 「まばたきの修正を設定しました」と出たら完了です

   ![完了ダイアログ「まばたきの修正を設定しました。アップロード時に自動で反映されます。」](/images/fixed-dialog.png)

4. あとはアップロードするだけです。修正は自動で反映されます

アバターの下に「Avatar Blink Fix (NDMF)」というオブジェクトが追加されます。設定は全部この子が持っています。

![修正後のインスペクタ。検出数の行と「表情を再読み込み」「プレビューを終了」ボタンが並ぶ](/images/easy-normal.png)

## その場で修正後の顔を確認できます

自動修正を押すとプレビューが自動でONになるので、シーン上のアバターも修正後の顔になります。
直っているかどうか、その場で目で確かめられます。

インスペクタのボタンが赤い「**プレビューを終了**」になっていれば、プレビューON の状態です。

::: tip 実際に直っているのはアップロードのとき
この方式は非破壊なので、元のメッシュには手を付けていません。プレビューは修正後の見え方を映しているだけで、実際の修正は**アップロード（ビルド）のときに適用されます**。
プレビューを終了しても、アップロード時には修正されます。
:::

## あとから表情改変をやり直すとき

::: warning 先に「プレビューを終了」してください
プレビュー中は、修正済みのメッシュに差し替わって表示されています。
**その状態のまま表情改変をすると、意図しない結果になることがあります。**
:::

1. インスペクタの「**プレビューを終了**」を押す
2. 表情改変をやり直す
3. 「**表情を再読み込み**」を押す

修正の設定は、自動修正を押した時点の BlendShape の値を覚えています。改変し直したら、3の「表情を再読み込み」で覚え直させてください。

追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除して、もう一度右クリック →「自動修正（推奨）」でも同じ結果になります。やりやすいほうでどうぞ。

## 元に戻したいとき

追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除してください。メッシュは触っていないので完全に元通りです。

## 「表情アニメーションとの競合」と出たら

表情アニメーションが、修正対象の BlendShape を動かしているのを見つけた状態です。
そのままだと、ゲーム内で表情を動かしたときに目の動きがおかしくなることがあります。

インスペクタに黄色い案内と「**ベイクモードに切り替える**」ボタンが出るので、押して[ベイクモード](/guide/bake)へ切り替えてください。表情を保ったまま修正できます。

→ 何が変わるのか気になるときは [ベイクモードと通常モード、何が違うの？](/guide/bake-vs-normal)

## プリセットが無いアバターの場合

Auto Fix プリセットが用意されていないアバターでも使えます。右クリック →「**手動修正**」で、直したい BlendShape を自分で選びます。

→ [手動修正（プリセットが無いアバター）](/guide/manual-fix)

対応アバターなのにプリセットが見つからない？ → [FAQ](/faq#preset-missing) をどうぞ。

## フェイストラッキング（FT）アバターの場合

FT 用の目閉じ BlendShape（EyeClosed 系など）を見つけると、修正に含めるかどうかの提案が出ます。

- 自動修正（通常モード）では、はじめは「含めない」になっています。FT 対応アバターは FT 側の仕組みで目閉じが調整されていることが多く、二重に直す必要がないためです
- ゲーム内で FT の目閉じが崩れるときだけ「含める」を選んでください
- [ベイクモード](/guide/bake)では逆に、はじめから「含める」になります（理由はベイクモードのページで）

## 表情アニメーションにまばたきを入れたいとき

作ってある表情アニメーションへ、まばたきを混ぜた新しいアニメーションを作れます（有料版）。

→ [まばたきと表情アニメーションの合成](/guide/animation)
