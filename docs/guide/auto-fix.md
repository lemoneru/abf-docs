# 自動修正（推奨）

[修正モードの選び方](/guide/bake-vs-normal)

対応するプリセットを使って、まばたきを自動で修正します。<br>
先に表情改変を済ませてから、修正してください。

## ① 自動修正を選ぶ

ヒエラルキーのアバターを右クリックして、［Avatar Blink Fix］→［自動修正（推奨）］を選びます。<br>
アバター内にAvatar Blink Fixのオブジェクトが追加され、修正後の表情が表示されます。

［自動修正（推奨）］がグレーで押せない場合は、[手動修正](/guide/manual-fix)で必要項目を選んでください。

## ② 修正後の表情を確認する

追加されたオブジェクトを選び、インスペクターを開いてください。<br>
［プレビューを終了］と表示されていれば、プレビューがONになっています。

![自動修正のインスペクター。「表情を再読み込み」と「プレビューを終了」のボタン](/images/easy-normal.png)

まばたきやウインクで目が閉じるか確認します。<br>
プレビューをOFFにしても、アップロード時には修正が反映されます。

アップロード前の表情アニメーションの確認は、[実際の修正の流れ](/guide/workflow)をご覧ください。

## あとから表情改変をやり直すとき

顔のBlendShapeを調整し直す場合は、先にプレビューをOFFにしてください。

1. インスペクターで［プレビューを終了］を押す
2. 表情を改変する
3. ［表情を再読み込み］を押す

オブジェクトを削除してから表情を改変し、最後にもう一度自動修正を行う方法でも構いません。

::: details オブジェクトを消さずに、もう一度自動修正した場合
「既にコンポーネントがあります。入れ替えますか？」と表示されます。<br>
［入れ替える］を押すと、現在の表情に合わせて設定が作り直されます。
:::

## 修正前に戻すとき

追加されたAvatar Blink Fixのオブジェクトを削除してください。<br>
元のメッシュは書き換えていないため、修正前の状態に戻ります。

## こんなときは

<div class="usage-branch">

### 表情アニメーションとの競合がある場合

修正対象のBlendShapeを表情アニメーションが動かしていると、ゲーム内で目の形が崩れることがあります。

元の表情アニメーションを編集せずに使う場合は、［ベイクモードに切り替える］をお試しください。<br>
設定を引き継いで[ベイクモード](/guide/bake)へ切り替わり、破綻を軽減できる可能性があります。

※ ベイクモードはコンプリート版の機能です。100を超える値やマイナス値（限界突破）で改変している場合も、こちらをご利用ください。

</div>

<div class="usage-branch">

### フェイストラッキングを使う場合

フェイストラッキングを使う場合は、ベイクモードがおすすめです。<br>
インスペクターで［ベイクモードに切り替える］を押してください。

FT用BlendShapeの設定は、[フェイストラッキングのページ](/guide/face-tracking)をご確認ください。

</div>

対応アバターなのにプリセットが見つからない場合は、[よくある質問（FAQ）](/faq#preset-missing)をご確認ください。
