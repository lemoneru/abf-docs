# 自動修正（推奨）

いちばん簡単な使い方です。まずはこの方法をお試しください。

## 手順

1. ヒエラルキーで**アバターを右クリック**
2. 「**Avatar Blink Fix**」→「**自動修正（推奨）**」を選ぶ
3. 「まばたきの修正を設定しました」と表示されたら完了
4. そのまま**アップロード**すれば、修正が適用されています

アバターの直下に「Avatar Blink Fix (NDMF)」というオブジェクトが追加されます。設定はすべてこのオブジェクトが持っています。

## シーン上で見た目が変わらないのは正常です

この方式は**非破壊**です。メッシュは書き換えず、**アップロード（ビルド）時に自動で修正が適用されます**。
シーン上のアバターの見た目が変わらなくても、心配いりません。

修正後の見た目をその場で確かめたいときは、インスペクタの「**修正後をプレビュー**」を押してください。
確認が終わったら「**プレビューを終了**」で戻せます。**プレビューを終了しても、アップロード時にはちゃんと修正されます。**

## 元に戻したいとき

追加された「Avatar Blink Fix (NDMF)」オブジェクトを**削除するだけ**です。メッシュには手を加えていないので、完全に元通りになります。

## あとから表情改変を変えたとき

修正の設定は「自動修正を押した時点」の BlendShape の値を記録しています。
そのあとで表情改変をやり直した場合は、インスペクタの「**表情を再読み込み**」を押して、記録を今の状態に更新してください。

## 「表情アニメーションとの競合」と表示されたら

表情アニメーションが、修正対象の BlendShape を操作していることを検知した状態です。
そのままでは、**ゲーム内で表情を動かしたときに目の動きがおかしくなる**ことがあります。

インスペクタに黄色い案内と「**ベイクモードに切り替える**」ボタンが表示されるので、ボタンを押して[ベイクモード](/guide/bake)に切り替えてください。

## 非対応アバターの場合（手動修正）

Auto Fix プリセットが用意されていないアバターでも使えます。

1. アバターを右クリック →「**Avatar Blink Fix**」→「**手動修正**」
2. 詳細設定の一覧が開くので、**目を変形させている BlendShape** にチェックを入れる
3. あとは自動修正と同じです。そのままアップロードすれば適用されます

::: tip チェックを入れる基準
「完全に目を閉じる」BlendShape だけを対象にしてください。まつ毛の位置調整や半目など、閉じきらないものを含めると、まばたきが不自然になることがあります。
:::

対応アバターなのにプリセットが見つからないと表示される場合は、[FAQ](/faq#preset-missing) をご覧ください。

## フェイストラッキング（FT）アバターの場合

FT 用の目閉じ BlendShape（EyeClosed 系など）を検出すると、修正に含めるかどうかの提案が表示されます。

- **自動修正（通常モード）では、既定で「含めない」です。** FT 対応アバターは FT 側の仕組みで目閉じが調整されていることが多く、二重に修正する必要がないためです
- ゲーム内で FT の目閉じが崩れる場合だけ、「含める」を選んでください
- [ベイクモード](/guide/bake)では逆に既定で「含める」になります（理由はベイクモードのページで説明しています）
