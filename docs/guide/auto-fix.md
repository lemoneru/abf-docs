# 自動修正（推奨）

いちばん簡単な使い方です。まずはこれをどうぞ。

## 手順

1. ヒエラルキーで**アバターを右クリック**
2. 「**Avatar Blink Fix**」→「**自動修正（推奨）**」を選ぶ
3. 「まばたきの修正を設定しました」と出たら完了！
4. あとは**アップロードするだけ**。修正は自動で反映されます

アバターの下に「Avatar Blink Fix (NDMF)」というオブジェクトが追加されます。設定は全部この子が持っています。

## 見た目が変わらない…？ それで正常です

この方式は**非破壊**。メッシュには手を付けず、**アップロード（ビルド）のときに修正が適用されます**。
シーン上のアバターが何も変わっていなくても、壊れているわけではないので安心してください。

その場で確かめたいときは、インスペクタの「**修正後をプレビュー**」を押せば修正後の顔が見られます。
見終わったら「**プレビューを終了**」で元に戻してOK。**プレビューを終了しても、アップロード時にはちゃんと修正されます。**

## 元に戻したいとき

追加された「Avatar Blink Fix (NDMF)」オブジェクトを**削除するだけ**。メッシュは触っていないので、完全に元通りです。

## あとから表情改変を変えたとき

修正の設定は「自動修正を押した時点」の BlendShape の値を覚えています。
そのあと表情改変をやり直したら、インスペクタの「**表情を再読み込み**」を押して覚え直させてください。

## 「表情アニメーションとの競合」と出たら

表情アニメーションが、修正対象の BlendShape を動かしているのを見つけた状態です。
そのままだと、**ゲーム内で表情を動かしたときに目の動きがおかしくなる**ことがあります。

インスペクタに黄色い案内と「**ベイクモードに切り替える**」ボタンが出るので、押して[ベイクモード](/guide/bake)へ切り替えてください。それだけで大丈夫です。

## 非対応アバターの場合（手動修正）

Auto Fix プリセットがないアバターでも使えます。

1. アバターを右クリック →「**Avatar Blink Fix**」→「**手動修正**」
2. 詳細設定の一覧が開くので、**目を変形させている BlendShape** にチェックを入れる
3. あとは自動修正と同じ。そのままアップロードすれば適用されます

::: tip チェックを入れる基準
「完全に目を閉じる」BlendShape だけを選ぶのがコツです。まつ毛の位置調整や半目など、閉じきらないものまで入れると、まばたきが不自然になることがあります。
:::

対応アバターなのにプリセットが見つからない？ → [FAQ](/faq#preset-missing) をどうぞ。

## フェイストラッキング（FT）アバターの場合

FT 用の目閉じ BlendShape（EyeClosed 系など）を見つけると、修正に含めるかどうかの提案が出ます。

- **自動修正（通常モード）では、はじめは「含めない」になっています。** FT 対応アバターは FT 側の仕組みで目閉じが調整されていることが多く、二重に直す必要がないためです
- ゲーム内で FT の目閉じが崩れるときだけ「含める」を選んでください
- [ベイクモード](/guide/bake)では逆に、はじめから「含める」になります（理由はベイクモードのページで）
