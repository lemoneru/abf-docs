# コンプリート版へのアップグレード

購入済みの方は、解除キーを1回インポートすればコンプリート版を使えます。
ツールに「コンプリート版の機能です」と表示された場合も、次の手順で解除できます。

## まず、この3つ

1. [BOOTHのライブラリ](https://accounts.booth.pm/library)から、Avatar Blink Fixの**最新の解除キー**をダウンロードする
2. `AvatarBlinkFix_UnlockKey.unitypackage` を開き、Unityへインポートする
3. 「コンプリート版になりました」と表示されたら完了

![解除成功のダイアログ「コンプリート版になりました」](/images/unlock-dialog.png)

::: tip 別のプロジェクトでは
同じPCなら、通常は解除キーをもう一度入れる必要はありません。ほかのプロジェクトでもコンプリート版として使えます。
ツールのアップデート後も、解除キーの入れ直しは不要です。
:::

::: details 無料版を消してから入れ直す必要はある？
ありません。無料版を入れたプロジェクトに、解除キーをインポートするだけでアップグレードできます。
:::

::: tip 無料版のときに設定したアバターがある場合
無料版で作った設定は、修正対象が1つだけの状態で保存されています。
アップグレード後、インスペクタの［表情を再読み込み］を押すと、修正対象をコンプリート版の内容で設定し直せます。
ツール側にも同じ案内が出ます。押し忘れてもアバターが壊れることはありません。
:::

## 解除キーとは

購入済みの機能を使えるようにするための、小さな `.unitypackage` です。

まだ購入していない方は、[Avatar Blink Fixの販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)から購入できます。機能の違いは[無料版と有料版の違い](/guide/editions)をご覧ください。

- ツール本体は [VCC / ALCOM](/add) から入れます
- 解除キーはBOOTHから別にダウンロードして、Unityへインポートします
- 2.xをご購入済みの方も、3.0用の解除キーが必要です。追加料金はかかりません
- 解除キーは購入者本人用です。ほかの方へ渡したり、再配布したりしないでください

2.xから更新する場合は、[2.xをお使いの方へ](/guide/from-2x)もあわせてご覧ください。

## 入れてもトライアル版のままのとき

BOOTHのライブラリから最新の解除キーをダウンロードし、もう一度インポートしてください。古い解除キーは上書きされます。

**2026年8月24日より前にダウンロードした解除キーは使えません。** 最新版を使ってください。

プロジェクトから解除キーのアセットを消しても、同じPCでは通常、コンプリート版の状態が残ります。

## トライアル版へ戻す

Unityの上部メニューから **Tools → Avatar Blink Fix** を開き、［トライアル版に戻す］を押してください。プロジェクト内に解除キーのアセットが残っている場合は、確認後にあわせて削除されます。
