# コンプリート版へのアップグレード

[BOOTH](https://lemoneru.booth.pm/items/7074770)でコンプリート版または支援版をご購入いただき、ダウンロードできる「解除キー」をインポートすると、同じPCのすべてのプロジェクトでコンプリート版として使えます。

## アップグレード方法

1. [BOOTH](https://lemoneru.booth.pm/items/7074770)から解除キーをダウンロードする
2. `AvatarBlinkFix_UnlockKey.unitypackage` を開き、Unityへインポートする
3. 「コンプリート版になりました」と表示されたら完了

::: tip 別のプロジェクトでは
同じPCなら、ほかのプロジェクトで解除キーをもう一度入れる必要はありません。
:::
