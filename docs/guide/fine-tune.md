# BlendShapeの微調整・入れ替え

::: info 3.0.17以降の機能
VCC / ALCOMから3.0.17以降へ更新してご利用ください。
:::

選んだBlendShapeの形を、プレビューを見ながら好みに合わせて調整できます。<br>
元の形を弱める、別の形を足す、形を入れ替える操作で、そのBlendShapeの仕上がりを決めます。

コンプリート版の機能です。<br>
自動修正（推奨）・自動修正（ベイクモード）のどちらでも使えます。

## ① 微調整を開く

1. 自動修正したアバター内の、Avatar Blink Fixのオブジェクトを選びます。
2. インスペクターの［詳細設定］を開き、下部の［BlendShapeの微調整・入れ替え］を押します。
3. 顔画像つきの一覧から、調整したいBlendShapeの［編集する］を押してください。名前で検索することもできます。

最初の一覧には、自動修正の対象に選んだBlendShapeが表示されます。<br>
青い［編集中］欄で、どのBlendShapeを調整しているか確認してください。

### 任意のBlendShapeを選ぶ {#other-blendshapes}

::: info 次回アップデートで追加予定
以下の対象選択は、公開版3.0.17には含まれていません。
:::

同じメッシュ内の任意のBlendShapeを選び、仕上がりの形を調整できます。

1. 一覧の検索欄の下にある［詳細オプション］を開きます。
2. ［修正対象以外のBlendShapeも表示］をONにします。
3. ［その他のBlendShape］から調整したいものを選び、［編集する］を押します。

自動修正の対象にチェックを追加する必要はありません。<br>
選んだBlendShapeの名前はそのままで、形をこの画面で調整したものに変更できます。

## ② 形を整える

必要な操作だけを使ってください。

### 元の形を弱める

［元の形の強さ］を0～100%で調整します。<br>
例えば、目を閉じる形を少し弱めたい場合は、顔を見ながら数値を下げてください。

0%にすると元の形による変形がなくなり、別に足した形だけが残ります。

### 別の形を足す

［別の形を足す］を開き、追加したいBlendShapeを選びます。<br>
名前にマウスを重ねると、50%足した形を一時的に確認できます。マウスを離すと戻り、この確認だけでは設定は変わりません。

使いたいものを選んだら、追加した形の数値と、適用する範囲［両方］［左］［右］を調整してください。<br>
例えば、まばたきに目元の形を少し足して、閉じたときの印象を整えられます。

### 別の形に入れ替える

［別の形に入れ替える］→［選ぶ］を押すと、修正対象の候補が表示されます。<br>
候補にマウスを重ねる間だけ、入れ替え後の形を確認できます。使いたい候補をクリックして選んでください。

例えば、まばたきの形を笑い目の形に入れ替えられます。<br>
変わるのは形だけで、編集中のBlendShapeの名前は変わりません。

入れ替えを解除する場合は、［修正済みの形に戻す］を押してください。

任意のBlendShapeを候補に出す場合も、一覧の［修正対象以外のBlendShapeも表示］をONにします（上記の追加予定機能）。

## ③ 変更を保存する

形が決まったら［変更を保存］を押してください。<br>
調整した内容がAvatar Blink Fixの設定へ保存され、修正結果に反映されます。その後、Unityのシーンも保存してください。

別のBlendShapeも調整する場合は、［一覧に戻る］から選び直せます。<br>
［修正対象以外のBlendShapeも表示］をOFFにしても、保存した調整は残ります。

保存後は、まばたきや表情アニメーションを動かして確認してください。<br>
この機能で変えるのはBlendShapeの形です。アニメーションファイルの数値や動きは変更しません。

## 調整を戻す

1つのBlendShapeの調整を戻す場合は、［元の形の強さ］を100%に戻し、足した形を［×］で外してください。<br>
入れ替えも行っている場合は、［修正済みの形に戻す］を押し、最後に［変更を保存］を押します。

一覧の［すべて元に戻す］では、非表示の項目も含め、この画面で行った微調整と入れ替えをまとめて解除します。<br>
解除した状態を残す場合も［変更を保存］を押してください。

::: details 「複数フレーム」の注意が表示された場合
複数段階の形状が登録されたBlendShapeでは、微調整するのは最初のフレームだけです。足す形や入れ替える形も、最初のフレームを使います。<br>
後の段階は変わらないため、100%の形が変わらない場合があります。実際に使う値でも見た目を確認してください。
:::
