# 手動修正（プリセットが無いアバター）

**Auto Fix プリセットが用意されていないアバターでも、Avatar Blink Fix は使えます。**
どの BlendShape を直すかを自分で選ぶだけで、あとは自動修正と同じように動きます。

::: tip まずは「自動修正（推奨）」を試してください
プリセットがあるアバターなら、[自動修正](/guide/auto-fix)が全部選んでくれます。
このページは、**プリセットが無い／合わないと表示されたとき**の進め方です。
:::

## 全体の流れ

> **① 表情改変を終わらせる → ② 右クリックで「手動修正」→ ③ 一覧を編集できるようにする → ④ 目を変形させているBlendShapeを確認 → ⑤ 修正対象のBlendShapeを選ぶ → ⑥ プレビューで確認 → ⑦ アップロード**

## ① 先に表情改変を終わらせる

手動修正でも、ツールは「**設定した時点の BlendShape の値**」を見て動きます。
先に表情改変を終わらせてから始めてください。

## ② アバターを右クリック →「手動修正」

1. **ヒエラルキーのアバターを右クリック**
2. 「**Avatar Blink Fix**」→「**手動修正**」を選ぶ

![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

::: details 「自動修正（推奨）」が押せないとき
そのアバター用のプリセットが無い（または合わない）状態です。**押せないのが正常**なので、「手動修正」へ進んでください。

「手動修正」は**プリセットがあるアバターでも選べます**。自分で選び直したいときにも使えます。
:::

## ③ 一覧を編集できるようにする

コンポーネントが追加され、インスペクタの「**詳細設定**」が開いた状態になります。

::: warning このとき、一覧はグレーアウトして触れません
追加した直後は**プレビューが自動でONになる**ため、一覧が編集できない状態になっています。
「※ [プレビューを終了]を押すと変更できます」と表示されているはずです。
:::

編集できるようにする方法は2つあります。どちらでも構いません。

- 「**手動で編集する**」にチェックを入れる … 編集のあいだプレビューが自動で止まり、チェックを戻すと再開します（**こちらが楽です**）
- 「**プレビューを終了**」を押す

## ④ 「目を変形させているBlendShape」を確認する

**表情改変で値を変えた BlendShape** の一覧です。
修正のときに「**改変ぶんを打ち消す**」ために使われます。ここが修正の土台になります。

**ふつうは自動で検出されるので、そのままで大丈夫です。** 表情改変で触ったものが入っていれば問題ありません。

- 赤い名前は「**修正非推奨**」の印です
- ここが**1つも無いと、⑥のプレビューが押せません**（後述）

::: tip 空っぽのときは
「目の変形が見つかりません」と出ていたら、**顔のメッシュの BlendShape の値を変えていない**状態です。
表情改変をしてから「**表情を再読み込み**」を押してください。
:::

## ⑤ 「修正対象のBlendShape」を選ぶ

**ここが手動修正の本番です。** 直したい（作り直したい）BlendShape に、自分でチェックを入れます。

### 何を選ぶか

**「完全に目を閉じる」BlendShape だけ**を選ぶのがコツです。

| 選ぶ | 選ばない |
|---|---|
| まばたき（`vrc.blink` / `eye_close` など） | まつ毛の位置調整 |
| ウィンク（左右別のもの） | 半目・ジト目 |
| 笑い目など、**閉じきる**表情 | 目のサイズ変更・顔全体の形が変わるもの |

閉じきらないものまで入れると、**まばたきが不自然になります**。
迷ったら、**まずはまばたき用の1つだけ**で試してみてください。あとから増やせます。

### 名前の色が目印です

一覧の上に「**シアン＝推奨 / グレー＝選択不可**」と出ています。

- **シアン色** … おすすめの候補。**まずはここから選んでください**
- **グレー** … 選べないもの（→ [FAQ](/faq#used-in-expression)）
- **赤色** … 顔全体を変形させるもの。選ぶと、**打ち消したときに顔立ちごと元に戻ってしまう**ことがあります

::: danger 表情改変に使った BlendShape は選ばないでください
表情に使っている BlendShape を修正すると、**せっかく作った表情のほうが変わってしまいます。**

ふつうはグレーアウトして選べませんが、「**手動で編集する**」をONにしていると**選べてしまうことがあります**。
④の「目を変形させているBlendShape」に入っているものは、こちらでは選ばないでください。
:::

## ⑥ プレビューで確認する

チェックが終わったら、修正後の顔を確認します。

- 「**手動で編集する**」を使った場合 … チェックを**OFFに戻す**とプレビューが再開します
- 「**プレビューを終了**」を押していた場合 … 「**修正後をプレビュー**」を押します

::: warning 「修正後をプレビュー」がグレーで押せないとき
④の「**目を変形させているBlendShape**」が0件だと、このボタンは押せません。

「**表情を再読み込み**」を押してください。アバターに合わせて自動で設定し直します。
それでも0件のままなら、**まだ顔の BlendShape の値を変えていない**状態です（→ [FAQ](/faq#no-modification)）。
:::

思ったとおりの形になっていなければ、⑤に戻ってチェックを調整してください。

## ⑦ そのままアップロード

**特別な操作はいりません。** いつもどおりアップロードすれば、**修正が適用された状態で**アバターが上がります。
プレビューを終了していても、アップロード時にはきちんと修正が入ります。

**やめたくなったら**、追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除するだけです。メッシュは触っていないので、完全に元通りになります。

## 選び直したくなったら

「**表情を再読み込み**」を押すと、**アバターに合わせた自動設定に戻ります**。手動で入れたチェックをやり直したいときにどうぞ。

## うまくいかないときは

- 一覧に何も出てこない → [FAQ: 「目の変形が見つかりません」と出る](/faq#no-modification)
- 顔のメッシュが違うものになっている → [FAQ: 顔のメッシュが自動で見つからない](/faq#face-not-found)
- 直したい BlendShape にチェックが入れられない → [FAQ: 表情改変に使った BlendShape](/faq#used-in-expression)
- ゲーム内で表情を動かすと崩れる → [ベイクモード（強化版）](/guide/bake)

## プリセットのリクエストもできます

お使いのアバターのプリセットが無い場合は、[Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)のメッセージからリクエストいただけます。
対応できたものは、アップデートで同梱されます。
