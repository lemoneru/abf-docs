# 手動修正（プリセットが無いアバター）

**Auto Fix プリセットが用意されていないアバターでも、Avatar Blink Fix は使えます。**
どの BlendShape を直すかを自分で選ぶだけで、あとは自動修正と同じように動きます。

::: tip まずは「自動修正（推奨）」を試してください
プリセットがあるアバターなら、[自動修正](/guide/auto-fix)が全部選んでくれます。
このページは、**プリセットが無い／合わないと表示されたとき**の進め方です。
:::

## 手順

1. **ヒエラルキーのアバターを右クリック**
2. 「**Avatar Blink Fix**」→「**手動修正**」を選ぶ

   ![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

3. インスペクタの「**詳細設定**」が開いた状態でコンポーネントが追加されます
4. 「**修正対象のBlendShape**」の一覧から、**目を閉じる BlendShape にチェック**を入れる
5. そのまま**アップロード**すれば、修正が適用されます

チェックを入れると自動でプレビューに反映されるので、**その場で結果を見ながら**選べます。

## どれを選べばいい？

**「完全に目を閉じる」BlendShape だけ**を選ぶのがコツです。

| 選ぶ | 選ばない |
|---|---|
| まばたき（`vrc.blink` / `eye_close` など） | まつ毛の位置調整 |
| ウィンク（左右別のもの） | 半目・ジト目 |
| 笑い目など、**閉じきる**表情 | 目のサイズ変更・顔全体の形が変わるもの |

閉じきらないものまで入れると、**まばたきが不自然になります**。迷ったら、まずはまばたき用の1つだけで試してみてください。

::: warning 赤字で表示される BlendShape に注意
顔全体を変形させる BlendShape は**赤字**で表示されます。これを対象にすると、打ち消したときに顔立ちごと元に戻ってしまうことがあります。
:::

## 一覧の見かた

詳細設定の中には、2つの一覧があります。

**目を変形させているBlendShape**
表情改変で値を変えた BlendShape です。修正のときに「打ち消す」ために使われます。
ふつうは自動で検出されるので、そのままで大丈夫です。

**修正対象のBlendShape**
まばたきなど、**直したい BlendShape** です。手動修正ではここにチェックを入れます。

- **シアン色** … おすすめの候補
- **グレー** … 選べないもの（表情改変に使っている BlendShape。理由は [FAQ](/faq#used-in-expression) へ）
- **赤色** … 顔全体が変わるので注意

## チェックが変更できないとき

一覧がグレーアウトして触れない場合は、「**手動で編集する**」にチェックを入れてください。
プリセットどおりの状態に戻したくなったら、「**表情を再読み込み**」を押せば元に戻ります。

::: tip 手動編集の間はプレビューが止まります
編集中は修正のプレビューを一時停止しています。「手動で編集する」をOFFに戻すと再開します。
:::

## うまくいかないときは

- 一覧に何も出てこない → [FAQ: 「目の変形が見つかりません」と出る](/faq#no-modification)
- 顔のメッシュが違うものになっている → [FAQ: 顔のメッシュが自動で見つからない](/faq#face-not-found)
- 直したい BlendShape にチェックが入れられない → [FAQ: 表情改変に使った BlendShape](/faq#used-in-expression)
- ゲーム内で表情を動かすと崩れる → [ベイクモード](/guide/bake)

## プリセットのリクエストもできます

お使いのアバターのプリセットが無い場合は、[Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)のメッセージからリクエストいただけます。
対応できたものは、アップデートで同梱されます。
