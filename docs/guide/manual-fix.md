# 手動修正（プリセットが無いアバター）

Auto Fix プリセットが無いアバターでも使えます。
手動修正では、表情改変で目を変えた BlendShape と、直したいまばたき用の BlendShape を自分で選びます。

::: tip まずは「自動修正（推奨）」を試してください
プリセットがあるアバターなら、[自動修正](/guide/auto-fix)が全部選んでくれます。
このページは、「自動修正（推奨）」がグレーで押せないときの進め方です。
:::

## 全体の流れ

> **表情改変を終わらせる →「手動修正」を追加 → 2つの一覧を選ぶ → プレビューで確認 → アップロード**

## ① 先に表情改変を終わらせる

手動修正でも、ツールは設定した時点の BlendShape の値を見て動きます。
先に表情改変を終わらせてから始めてください。

## ② アバターを右クリック →「手動修正」

1. ヒエラルキーのアバターを右クリック
2. 「**Avatar Blink Fix**」→「**手動修正**」を選ぶ

![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

コンポーネントが追加され、インスペクタの「**詳細設定**」が開いた状態になります。

::: details 「自動修正（推奨）」が押せないとき
そのアバター用のプリセットが無い（または合わない）状態です。押せないのが正常なので、「手動修正」へ進んでください。

「手動修正」はプリセットがあるアバターでも選べます。自分で選び直したいときにも使えます。
:::

## ③ 「手動で編集する」にチェックが入っていることを確認する

「手動修正」から入ると、プレビューはOFF、「**手動で編集する**」はONの状態で始まります。すぐに一覧を触れる状態です。

もしチェックが外れていたら、入れてください。外れていると一覧はグレーアウトして触れません。

チェックが入っているあいだは、修正のプレビューが止まります。選び終えたらチェックを外し、⑥のプレビューボタンを押してください。

## ④ 「目を変形させているBlendShape」を選ぶ

表情改変で目の形を変えた BlendShape を登録するところです。
ここに入れたものは、修正のときに改変ぶんを打ち消すために使われます。**修正の土台になる、いちばん大事な一覧です。**

::: warning プリセットが無いときは、ここは空のままです
自動で入るのはプリセットに載っているアバターだけなので、手動修正では自分でチェックを入れる必要があります。

空のときは、一覧の下に「ここに、表情改変で目の形を変えたBlendShapeをチェックしてください」と案内が出ます。
:::

### 何を選ぶか

表情改変で値を変えた（0 以外になっている）もののうち、目の形に影響するものを選びます。
値は一覧のスライダーの数字で分かります。

| ○ 選ぶ | ✕ 選ばない |
|---|---|
| 目の**大きさ・開き具合**を変えたもの | **値が 0 のまま**のもの（改変で触っていない） |
| **つり目・たれ目**など、目の形を変えたもの | **口・眉・輪郭**など、目に関係しないもの |
| **まぶた・まつ毛の位置**を動かしたもの | ⑤で「修正対象」に選ぶもの（**両方には入れられません**） |

迷ったら、表情改変で自分が触った覚えのあるものを、目のまわりだけ入れてください。

## ⑤ 「修正対象のBlendShape」を選ぶ

直したい（作り直したい）BlendShape を選びます。

代表的なまばたき用の名前（`vrc.blink` など）は、プリセットが無くても自動でチェックが入ります。そのままで問題なければ、足す必要はありません。

### 何を選ぶか

まずは、普段のまばたきに使うものを1つ選びます。ウィンクや笑い目も直したい場合は、プレビューを見ながらあとから追加できます。

半目・ジト目・まつ毛の位置調整・目のサイズ変更などは、最初からまとめて選ばず、必要なものだけ1つずつ試してください。名前だけでは判断できないため、追加するたびにプレビューで目の動きを確認します。

### 名前の色が目印です

一覧の上に「シアン＝推奨 / グレー＝選択不可」と出ています。

- **シアン色** … おすすめの候補。まずはここから選んでください
- **グレー** … 選べないもの。④でチェックしたものや、表情改変に使っているものがここに入ります（→ [FAQ](/faq#used-in-expression)）

## ⑥ プレビューで確認する

「**手動で編集する**」のチェックをOFFに戻し、「**修正後をプレビュー**」を押します。
シーン上のアバターが修正後の顔になったら、まばたきやウィンクの形を確かめてください。

::: tip ボタンが「表情を読み込んでプレビュー」になっているとき
④の「目を変形させているBlendShape」がまだ0件の状態です。そのまま押して大丈夫です。
アバターに合わせて読み込み直してから、プレビューまで進みます。

押しても「目の変形が見つかりません」と出るときは、まだ顔の BlendShape の値を変えていない状態です（→ [FAQ](/faq#no-modification)）。
:::

思ったとおりの形になっていなければ、④⑤に戻って調整してください。

## ⑦ アップロードして、直っているか確かめる

いつもどおりアップロードすれば、修正が適用された状態でアバターが上がります。
プレビューを終了していても、アップロード時には修正が入ります。

アップロードしたら、**目の BlendShape が直っているか確認してください。**

::: tip ゲーム内で目の動きがおかしいときは
表情アニメーションと競合していることがあります。そのときは [ベイクモード](/guide/bake) を試してみてください。
→ [通常モードとの違い](/guide/bake-vs-normal)
:::

やめたくなったら、追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除してください。元のメッシュは書き換えていません。

## 選び直したくなったら

「**表情を再読み込み**」を押すと、アバターに合わせた自動設定に戻ります。手動で入れたチェックをやり直したいときにどうぞ。

## うまくいかないときは

- 一覧に何も出てこない → [FAQ: 「目の変形が見つかりません」と出る](/faq#no-modification)
- 顔のメッシュが違うものになっている → [FAQ: 顔のメッシュが自動で見つからない](/faq#face-not-found)
- 直したい BlendShape にチェックが入れられない → [FAQ: 表情改変に使った BlendShape](/faq#used-in-expression)
- ゲーム内で表情を動かすと崩れる → [ベイクモード](/guide/bake)

## プリセットは自分で作れます

同じアバターで何度も修正するなら、プリセットを作っておくと次から自動修正が使えます。

無料ツール「BlendShapeChecker」で、お使いのアバター用の Auto Fix プリセットを書き出せます。
書き出した JSON を `Assets/LEMONERU/Avatar Blink Fix/json` の**直下**に置くと、そのまま読み込まれます（フォルダが無ければ自動で作られます）。

→ [BlendShapeChecker（無料・BOOTH）](https://lemoneru.booth.pm/items/8361673)

作ったプリセットは、他の方と共有していただいてかまいません。
