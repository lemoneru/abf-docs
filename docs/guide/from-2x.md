# 2.x をお使いの方へ（3.0 への移行）

2.x をご購入済みの方は、**追加料金なしで 3.0 をお使いいただけます。**
**2.x で修正済みのアバターも、そのまま使い続けられます。**

::: danger 3.0 から「解除キー」方式になりました
2.x は、購入するとツール本体（unitypackage）がそのまま製品版でした。
**3.0 は、まず誰でも無料版として動き、そこへ「解除キー」を1回インポートするとコンプリート版になります。**

つまり **2.x をご購入済みの方も、3.0 では解除キーを入手していただく必要があります**（2.x に解除キーは入っていません）。
解除キーは、**一般公開（2026年9月4日）に合わせて BOOTH の購入ページで配布します。**
:::

## 「新しい Avatar Blink Fix への移行」と出たときは

3.0 を入れると、前のバージョンが残っている場合にこの案内が出ます。

### ［移行する］を押して大丈夫です

前のバージョンと重なったままだと正しく動かないので、新しい版だけが動くように整理します。

| 移動するもの | そのまま残るもの |
|---|---|
| **ツール本体のファイルだけ** | **`Data`**（修正の記録） |
| | **`Animation`**（生成したアニメーション） |
| | **自分で追加したプリセット** |
| | **修正済みのアバター**（そのまま使えます） |

**ファイルはごみ箱へ移すだけなので、いつでも元に戻せます。** 何を移したかは、Unity の Console に一覧が出ます。

::: tip ［あとで］を押しても壊れません
2.x が残っていても、警告が出るだけでプロジェクトは動きます。あとから Tools →「Avatar Blink Fix」の「**新しい版へ移行**」からいつでもできます。
:::

::: warning 3.0 のベータ版（8月のテスト版）を試された方だけ、例外です
`Assets\LEMONERU\Avatar Blink Fix\` に **`Editor` フォルダがある**場合は、VCC / ALCOM で入れる前に、**`Editor`・`Runtime`・`json` を先に削除してください。**
（`Data`・`Animation` は残してください）

消さずに入れると、名前の重複で **Unity がセーフモードに入ります**。
:::

## 入れる前にやることはありません

**前のバージョンは、先に消さなくて大丈夫です。** そのまま [導入方法](/guide/install) のとおりに 3.0 を入れてください。

## 3.0 で変わったこと

### ① VPMリポジトリに対応しました（VCC / ALCOM に直接導入）

今までの「アップデートのたびに unitypackage を入れ直す」作業がなくなりました。
一度リポジトリを追加してしまえば、**新しいバージョンが出たら「更新」を押すだけ**です。

![ALCOMのパッケージ管理画面。Avatar Blink Fix の行と追加ボタン](/images/alcom-add-package.png)

→ 入れ方は [導入方法](/guide/install) へ。今までどおりの unitypackage も同梱しています。

### ② 修正方法が新しくなりました

**ヒエラルキーのアバターを右クリック →「Avatar Blink Fix」→「自動修正（推奨）」。これだけです。**

![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

- 2.x と違って**メッシュを書き換えません**（非破壊）。修正はアップロード時に自動で反映されます
- 押すとプレビューがONになるので、**その場で修正後の顔を確認できます**
- 元に戻すときは、追加されたオブジェクトを削除するだけ
- くわしくは → [自動修正（推奨）](/guide/auto-fix)

::: warning 表情改変をやり直すときは
プレビュー中は修正済みのメッシュに差し替わっています。**いったん「プレビューを終了」してから**改変し、終わったら「**表情を再読み込み**」を押してください（→ [くわしく](/guide/auto-fix#あとから表情改変をやり直すとき)）。
:::

::: tip 今までのウィンドウもそのまま使えます
2.x と同じ操作の窓は「[メッシュ入れ替え式](/guide/meshswap)」として残っています。従来どおりの修正もできますが、**まずは右クリックの自動修正をおすすめします**。
:::

### ③ 新モード「ベイクモード」が増えました

表情アニメーションが目の BlendShape を動かしていて、**修正してもゲーム内で目がおかしくなる**——2.x でときどき起きたあの症状に、正面から対応する新モードです。改変した表情をメッシュに焼き込んでから修正するので、表情アニメーションを使っていても崩れにくくなります。

→ 使いどころと手順は [ベイクモード](/guide/bake) へ。自動修正が競合を見つけると、切り替えボタン付きで案内してくれるので、覚えておかなくても大丈夫です。

## で、結局なにをすればいい？

1. **[導入方法](/guide/install)のとおり 3.0 を入れる**（VCC / ALCOM がおすすめ）。**前のバージョンは先に消さなくて大丈夫です**
2. 「**新しい Avatar Blink Fix への移行**」の案内が出たら「**移行する**」を押す
3. **2.x で修正済みのアバターは、なにもしなくてそのまま使えます**
4. 次にアバターを改変したときから、右クリック →「**自動修正（推奨）**」をどうぞ

::: details 2.x で修正済みのアバターに、間違えて右クリック修正しちゃったら？
大丈夫です。3.0 が検知して案内を出すので、二重に修正されて壊れることはありません。
:::

## 2.x へ戻したくなったら

1. **Unity を閉じて**、ごみ箱から前のバージョンのフォルダを戻す
2. ごみ箱が空になっていたら、[Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)の **2.x 最終版**から入れ直してください
3. 3.0 を外すときは、VCC / ALCOM の Manage Project から削除します

**`Data`・`Animation` はそのまま残してください**（2.x の修正の記録です）。3.0 の解除キーを入れてあっても、2.x の動作には影響しません。
