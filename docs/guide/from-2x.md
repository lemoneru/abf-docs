# 2.x をお使いの方へ（3.0 で変わったこと）

2.x をご購入済みの方は、**追加料金なしでそのまま 3.0 を使えます**。
大きく変わったのは、次の **2つ + 新モード1つ** です。

## ① VPMリポジトリに対応しました（VCC / ALCOM に直接導入）

今までの「アップデートのたびに unitypackage を入れ直す」作業がなくなりました。
一度リポジトリを追加してしまえば、**新しいバージョンが出たら「更新」を押すだけ**です。

![ALCOMのパッケージ管理画面。Avatar Blink Fix の行と追加ボタン](/images/alcom-add-package.png)

→ 入れ方は [導入方法](/guide/install) へ。今までどおりの unitypackage も同梱しているので、急いで乗り換えなくても大丈夫です。

## ② 修正方法が新しくなりました

**ヒエラルキーのアバターを右クリック →「Avatar Blink Fix」→「自動修正（推奨）」。これだけです。**

![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

- 2.x と違って**メッシュを書き換えません**（非破壊）。修正はアップロード時に自動で反映されます
- 押すとプレビューがONになるので、**その場で修正後の顔を確認できます**
- 元に戻すときは、追加されたオブジェクトを削除するだけ
- くわしくは → [自動修正（推奨）](/guide/auto-fix)

::: warning 表情改変をやり直すときは
プレビュー中は修正済みのメッシュに差し替わっています。**いったん「プレビューを終了」してから**改変し、終わったら「**表情を再読み込み**」を押してください（→ [くわしく](/guide/auto-fix#あとから表情改変をやり直すとき)）。
:::

::: tip 今までのウィンドウもそのまま使えます
2.x と同じ操作の窓は「[メッシュ入れ替え式](/guide/meshswap)」として残っています。従来どおりの修正もできますが、**まずは右クリックの自動修正をおすすめします**。
:::

## ③ 新モード「ベイクモード」が増えました

表情アニメーションが目の BlendShape を動かしていて、**修正してもゲーム内で目がおかしくなる**——2.x でときどき起きたあの症状に、正面から対応する新モードです。改変した表情をメッシュに焼き込んでから修正するので、表情アニメーションを使っていても崩れにくくなります。

→ 使いどころと手順は [ベイクモード](/guide/bake) へ。自動修正が競合を見つけると、切り替えボタン付きで案内してくれるので、覚えておかなくても大丈夫です。

## で、結局なにをすればいい？

1. **[導入方法](/guide/install)のとおり 3.0 を入れる**（VCC / ALCOM がおすすめ。上書きインポートでもOK）。**前のバージョンは、先に消さなくて大丈夫です**
2. 古い 2.x のファイルが残っていると「**新しい Avatar Blink Fix への移行**」の案内が出るので、「**移行する**」を押す
   （**設定も、修正したアバターも、そのまま使えます。** 前のバージョンのファイルはごみ箱へ移すだけなので、いつでも元に戻せます）
3. **2.x で修正済みのアバターは、なにもしなくてそのまま使えます**
4. 次にアバターを改変したときから、右クリック →「**自動修正（推奨）**」をどうぞ

::: details 2.x で修正済みのアバターに、間違えて右クリック修正しちゃったら？
大丈夫です。3.0 が検知して案内を出すので、二重に修正されて壊れることはありません。
:::
