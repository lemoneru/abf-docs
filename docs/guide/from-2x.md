# 2.x をお使いの方へ（3.0 への移行）

**先に要点だけ。**

- 2.x で修正したアバターは、**そのまま使えます**。3.0 を入れても壊れません
- **前の Avatar Blink Fix は、先に消さなくて大丈夫です。** そのまま[導入方法](/guide/install)のとおり 3.0 を入れてください
- 「新しい Avatar Blink Fix への移行」と出たら、**［移行する］を押して大丈夫です**
- 次にアバターを改変したときから、右クリック →「**自動修正（推奨）**」をどうぞ
- **追加料金はありません。** ただし 3.0 は「解除キー」方式です（すぐ下で説明します）

::: danger 3.0 から「解除キー」方式になりました
3.0 は、[Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)からダウンロードした解除キーを1回インポートすると、コンプリート版になります。

2.x をご購入済みの方も追加料金はかかりません。同じ購入ページから、3.0用の解除キーをダウンロードしてください。
:::

## 「新しい Avatar Blink Fix への移行」と出たときは

3.0 を入れると、前のバージョンが残っている場合にこの案内が出ます。

### ［移行する］を押して大丈夫です

前のバージョンと重なったままだと正しく動かないので、新しい版だけが動くように整理します。

| 移動するもの | そのまま残るもの |
|---|---|
| **ツール本体のファイルだけ** | **`Data`**（修正の記録） |
| | **`Animation`**（生成したアニメーション） |
| | **自分で追加したプリセット** |
| | **修正済みのアバター**（そのまま使えます） |

ファイルはごみ箱へ移すだけなので、いつでも元に戻せます。何を移したかは、Unity の Console に一覧が出ます。

::: tip ［あとで］を押しても壊れません
2.x が残っていても、警告が出るだけでプロジェクトは動きます。あとから Tools →「Avatar Blink Fix」の「**新しい版へ移行**」からいつでもできます。
:::

::: details 2.x で修正済みのアバターに、間違えて右クリック修正しちゃったら？
大丈夫です。3.0 が検知して「旧バージョン(2.x)の修正を検出」という案内を出すので、二重に修正されて壊れることはありません。

その画面では、**［そのまま使う］を押してください**。何も変わらず、2.x の修正のまま使い続けられます。
新しい非破壊方式に乗り換えたいときだけ［復元して移行］を選びます。2.x の修正をいったん元に戻してから、3.0 の方式で修正し直します。
:::

## 3.0 で変わったこと

### ① VPMリポジトリに対応しました（VCC / ALCOM に直接導入）

今までの、アップデートのたびに unitypackage を入れ直す作業がなくなりました。
一度リポジトリを追加してしまえば、新しいバージョンが出たら「更新」を押すだけです。

![ALCOMのパッケージ管理画面。Avatar Blink Fix の行と追加ボタン](/images/alcom-add-package.png)

→ 入れ方は [導入方法](/guide/install) へ。今までどおりの unitypackage も同梱しています。

### ② 修正方法が新しくなりました

ヒエラルキーのアバターを右クリックして、「Avatar Blink Fix」→「**自動修正（推奨）**」を選ぶ。作業はこれだけです。

![Hierarchyでアバターを右クリックし、「Avatar Blink Fix」から「自動修正（推奨）」を選ぶ操作図](/images/context-menu-guide.svg)

- 2.x と違って**メッシュを書き換えません**（非破壊）。修正はアップロード時に自動で反映されます
- 押すとプレビューがONになるので、その場で修正後の顔を確認できます
- 元に戻すときは、追加されたオブジェクトを削除してください
- くわしくは → [自動修正（推奨）](/guide/auto-fix)

::: warning 表情改変をやり直すときは
「**プレビューを終了**」してから改変し、終わったら「**表情を再読み込み**」を押してください。
表情改変ツールで表情Animationを作成・変更するときは、逆にプレビューをONのまま作業します。
→ くわしくは [自動修正: あとから表情改変をやり直すとき](/guide/auto-fix#あとから表情改変をやり直すとき)
:::

::: tip 今までのウィンドウもそのまま使えます
2.x と同じ操作の窓は「[メッシュ入れ替え式](/guide/meshswap)」として残っています。従来どおりの修正もできますが、まずは右クリックの自動修正をおすすめします。
:::

### ③ 新モード「ベイクモード」が増えました

2.x では、アバターに入っている表情Animationが目のBlendShapeを0で固定し、Unity上では直って見えても、ゲーム内では目がおかしくなることがありました。「キプフェル Kipfel」「Marycia マリシア」「あずき」などで見られた症状です。

ベイクモードは、改変した表情をメッシュに焼き込んでから修正します。表情Animationによる破綻を軽減できる可能性があります。

→ 使いどころと手順は [ベイクモード](/guide/bake) へ。自動修正が競合を見つけると、切り替えボタン付きで案内してくれるので、覚えておかなくても大丈夫です。

## 2.x へ戻したくなったら

::: warning 3.0 を残したまま 2.x を入れないでください
同じ名前のクラスやアセンブリが二重になり、Unity のコンパイルが止まることがあります。**3.0 を先に外してください。**
:::

1. **3.0 が入っているうちに**、アバター直下に 3.0 が追加した子オブジェクトがあれば削除し、シーン／Prefab を保存する
   （標準の名前は「Avatar Blink Fix (NDMF)」「Avatar Blink Fix (NDMF・トライアル)」「Avatar Blink Fix (Bake)」です。先に消しておかないと、外したあとに Missing Script が残ります）
2. **Unity を閉じる**
3. VCC / ALCOM の Manage Project から、Avatar Blink Fix 3.0 を**先に**外す
4. Unity を開き、[Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)にある **2.x 最終版のunitypackage**をインポートする
5. `Data`・`Animation`・`json`・解除キーは、そのまま残して大丈夫です

`Data`・`Animation` は 2.x の修正の記録です。3.0 の解除キーを入れてあっても、2.x の動作には影響しません。
