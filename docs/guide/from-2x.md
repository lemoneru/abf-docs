# 2.x をお使いの方へ（3.0 への移行）

3.0から解除キー方式になりました。解除キーを入れていない場合は、無料版（トライアル版）として動作します。

すでに2.xをお使いの方は、[Avatar Blink Fixの販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)からダウンロードした解除キーをインポートすると、コンプリート版になります。一度インポートすれば、以降は同じPCのすべてのプロジェクトでコンプリート版として使えます。

2.xをご購入済みの方に追加料金はかかりません。同じ購入ページにある3.0用の解除キーをご利用ください。

## 「新しい Avatar Blink Fix への移行」と出たときは

2.xが入っているプロジェクトに3.0を入れると、この案内が出ます。

［移行する］を選ぶと、以前のデータや設定を引き継いで3.0の機能を使えます。

::: tip ［あとで］を押した場合
あとから Tools → Avatar Blink Fix →［新しい版へ移行］で移行できます。
:::

## 2.xで修正済みのアバターを非破壊方式（NDMF）で修正するには

アバターを右クリックして、［Avatar Blink Fix］→［自動修正（推奨）］を選びます。

「旧バージョン(2.x)の修正を検出」と出たら、［復元して移行］を選んでください。2.xの修正を元に戻してから、非破壊修正用のオブジェクトが追加されます。

## 3.0 で変わったこと

### ① VPMリポジトリに対応しました（VCC / ALCOM に直接導入）

今までの、アップデートのたびに unitypackage を入れ直す作業がなくなりました。
一度リポジトリを追加してしまえば、新しいバージョンが出たら「更新」を押すだけです。

![ALCOMのパッケージ管理画面。Avatar Blink Fix の行と追加ボタン](/images/alcom-add-package.png)

→ 入れ方は [導入方法](/guide/install) へ。今までどおりの unitypackage も同梱しています。

### ② 修正方法が新しくなりました

ヒエラルキーのアバターを右クリックして、［Avatar Blink Fix］→［自動修正（推奨）］を選びます。<br>
アバター内にAvatar Blink Fixのオブジェクトが追加され、BlendShapeが修正された状態になります。

![Hierarchyでアバターを右クリックし、「Avatar Blink Fix」から「自動修正（推奨）」を選ぶ操作図](/images/context-menu-guide.svg)

アバターを修正前に戻すときは、追加されたAvatar Blink Fixのオブジェクトを削除してください。

→ [具体的な動作の流れ](/guide/workflow)

::: warning 表情改変をやり直すときは
Avatar Blink Fixのオブジェクトを削除するか、インスペクターでプレビューをOFFにしてから表情を改変してください。改変後は、オブジェクトを削除した場合はもう一度自動修正を行い、プレビューをOFFにした場合は［表情を再読み込み］を押します。

FaceEmoなどで表情アニメーションを作成・変更するときは、プレビューをONにすると、修正後の見た目を確認しながら作業できます。
:::

::: tip 今までの修正方法も使えます
今までどおり、Tools → Avatar Blink Fixからウィンドウを開いて修正することもできます。
:::

### ③ 新しい修正方法「ベイクモード」が実装されました

表情アニメーションとの競合による破綻を軽減できる可能性があります。アバター標準の表情アニメーションをそのまま使う場合や、フェイストラッキングなど特殊な表情アニメーションを使うアバターでお試しください。

改変した表情を、BlendShapeの値が0のときの形としてメッシュに焼き込んでから修正します。詳しくは[ベイクモード](/guide/bake)のページをご確認ください。

今までに近い使い方なら、通常の自動修正をご利用ください。ゲーム内でアニメーションが動いたときに目の形が崩れる場合は、ベイクモードに切り替えてお試しください。

## 2.x へ戻したくなったら

::: warning 3.0 を残したまま 2.x を入れないでください
同じ名前のクラスやアセンブリが二重になり、Unity のコンパイルが止まることがあります。**3.0 を先に外してください。**
:::

1. **3.0 が入っているうちに**、アバター直下に 3.0 が追加した子オブジェクトがあれば削除し、シーン／Prefab を保存する
   （標準の名前は「Avatar Blink Fix (NDMF)」「Avatar Blink Fix (NDMF・トライアル)」「Avatar Blink Fix (Bake)」です。先に消しておかないと、外したあとに Missing Script が残ります）
2. **Unity を閉じる**
3. VCC / ALCOM の Manage Project から、Avatar Blink Fix 3.0 を**先に**外す
4. Unity を開き、[Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770)にある **2.x 最終版のunitypackage**をインポートする
5. `Data`・`Animation`・`json`・解除キーは、そのまま残して大丈夫です

`Data`・`Animation` は 2.x の修正の記録です。3.0 の解除キーを入れてあっても、2.x の動作には影響しません。
