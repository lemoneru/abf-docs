# 導入方法

## 動作環境

- Unity 2022.3 系（VRChat 対応バージョン）
- 非破壊機能（[自動修正](/guide/auto-fix)・[ベイクモード](/guide/bake)）には **NDMF** が必要です
  - NDMF なしの環境でも[メッシュ入れ替え式](/guide/meshswap)は使えます

## VCC / ALCOM で導入する（おすすめ）

::: danger 現在は支援版をご購入いただいた方のみへの配布です
🔑 **アクティベートキーが無いと、コンプリート版としてはご利用いただけません**（導入しても**無料版として動作します**）。
アクティベートキーは、**支援版をご購入いただいた方がBOOTHの購入ページから入手できます**。一般公開後は、どなたでもご利用いただけるようになります。
:::

::: tip なぜ VCC / ALCOM がおすすめ？
アップデートのたびにファイルを入れ直さなくてよくなります。新しいバージョンが出たら「更新」を押すだけ！
:::

1. [利用規約](/terms)を確認してチェックを入れ、ボタンを押す（VCC / ALCOM が起動します）

   <AgreeInstall />

   ::: details ボタンで開かないときは
   VCC / ALCOM の設定 →「Packages」→「Add Repository」に、次のURLを貼り付けてください。

   ```
   https://lemoneru.github.io/vpm-repos/index.json
   ```

   ご購入者は、商品に同梱されている「**VCCに追加**」ショートカットからでも同じことができます。
   :::

2. リポジトリ「LEMONERU」を追加するか聞かれるので、承認する
3. プロジェクトのパッケージ管理で「**Avatar Blink Fix**」を探して、＋ボタンで追加する（検索欄に「blink」と入れると早いです）

   ![ALCOMのパッケージ管理画面。Avatar Blink Fix の行と追加ボタン](/images/alcom-add-package.png)

4. Unity でプロジェクトを開けば、もう使える状態です

## unitypackage で導入する

VCC / ALCOM を使わない場合向けに、unitypackage も同梱しています。プロジェクトにインポートすればそのまま使えます。
ただしアップデートのたびに入れ直しが必要になるので、特別な事情がなければ VCC / ALCOM のほうが楽です。

## 有料版へのアップグレード（ご購入者向け）

入れただけの状態では、**無料版**として動きます（自動で選ばれたまばたき用の BlendShape 1つを修正できます）。
どちらを使えばいいかは → [無料版と有料版の違い](/guide/editions)

ご購入者は、**同梱のファイル（解除キー）をプロジェクトに1回インポートするだけ**でアップグレード完了です。

- **同じ PC なら、ほかのプロジェクトでもそのまま有料版として使えます。** プロジェクトごとの作業はいりません
- 成功すると「コンプリート版になりました」と出ます

  ![解除成功のダイアログ「コンプリート版になりました」](/images/unlock-dialog.png)

- アップデート後も、入れ直しは不要です

::: details 無料版を消してから入れ直す必要はある？
ありません。無料版の上からインポートするだけで、残骸なくそのまま有料版になります。
:::

::: tip 無料版のときに設定したアバターがある場合
無料版で作った設定は、**修正対象が1つだけ**の状態で保存されています。
有料版にしたら、インスペクタの「**表情を再読み込み**」を押してください。すべてのBlendShapeを対象に設定し直します。
（ツール側にも同じ案内が出ます。押し忘れても壊れることはありません）
:::

## 2.x からのアップデート

**なにが変わったかは [2.x をお使いの方へ](/guide/from-2x) にまとめてあります。**

- 2.x をご購入済みの方は、追加料金なしでそのまま 3.0 を使えます
- **2.x で修正済みのアバターもそのまま使い続けられます。** 3.0 を入れても壊れません
  （修正済みアバターに右クリック修正をかけようとすると、ちゃんと検知して案内が出ます）
- **前のバージョンは、先に消さなくて大丈夫です。** そのまま 3.0 を入れてください
- 古い 2.x のファイルが残っていると、「**新しい Avatar Blink Fix への移行**」の案内が出ます。「**移行する**」を押せば、新しい版だけが動くように整理されます
  （**設定も、修正したアバターも、そのまま使えます。** 前のバージョンのファイルはごみ箱へ移すだけなので、いつでも元に戻せます）
- あとからでも、Tools →「Avatar Blink Fix」の「**新しい版へ移行**」からできます
