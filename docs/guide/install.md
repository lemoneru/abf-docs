# 導入方法

## 動作環境

- Unity 2022.3 系（VRChat 対応バージョン）
- 非破壊機能（[自動修正](/guide/auto-fix)・[ベイクモード](/guide/bake)）には **NDMF** が必要です
  - VCC / ALCOM 経由で導入すれば**自動で入ります**
  - NDMF なしの環境でも[メッシュ入れ替え式](/guide/meshswap)が使えます

## VCC / ALCOM で導入する（推奨）

::: tip なぜ VCC / ALCOM が推奨？
アップデートのたびにファイルを入れ直す必要がなくなります。新しいバージョンが出たら「更新」ボタンを押すだけです。
:::

1. 商品に同梱されている「**VCCに追加**」ショートカットを開く
   （または <https://lemoneru.github.io/vpm-repos/> を開いて「Add to VCC」を押す）
2. VCC / ALCOM にリポジトリ「LEMONERU」が追加されるので、承認する
3. 対象プロジェクトの「Manage Project」でパッケージ一覧から「**Avatar Blink Fix**」を追加する
4. Unity でプロジェクトを開くと、ツールが使える状態になっています

## unitypackage で導入する（VCC / ALCOM を使わない場合）

商品に unitypackage も同梱しています。プロジェクトにインポートすればそのまま使えます。
ただしアップデートのたびに入れ直しが必要になるため、特別な事情がなければ VCC / ALCOM をおすすめします。

## 解除キーのインポート（ご購入者）

導入しただけの状態では、無料の**トライアル版**として動作します（自動選択された1つの BlendShape のみ修正可能）。

ご購入者は、商品に同梱されている**解除キー（unitypackage）**をプロジェクトに1回インポートしてください。

- **同じ PC の全プロジェクトで解除されます**。プロジェクトごとの作業は不要です
- 解除に成功すると「コンプリート版になりました」という案内が表示されます
- ツールをアップデートしても、解除キーの再インポートは不要です

::: details トライアル版から製品版への切り替えで、入れ直しは必要？
不要です。トライアル版の上から解除キーをインポートするだけで、残骸なくそのまま製品版になります。
:::

## 2.x からのアップデート

- 2.x をご購入済みの方は、追加料金なしで 3.0 をご利用いただけます
- **2.x で修正済みのアバターはそのまま使い続けられます**。3.0 を導入しても壊れません
  （修正済みアバターを右クリック修正しようとした場合は、検知して案内が出ます）
- 古い本体（2.x のファイル）が残っている場合は、起動時に検出して「旧本体を削除」の案内が出ます。削除しても、生成済みのデータやプリセットの記録は残ります

導入できたら、[自動修正（推奨）](/guide/auto-fix)へ進んでください。
