# 導入方法

## 動作環境

- Unity 2022.3 系（VRChat 対応バージョン）
- 非破壊機能（[自動修正](/guide/auto-fix)・[ベイクモード](/guide/bake)）には **NDMF** が必要です
  - といっても、VCC / ALCOM 経由で入れれば**勝手に付いてきます**
  - NDMF なしの環境でも[メッシュ入れ替え式](/guide/meshswap)は使えます

## VCC / ALCOM で導入する（おすすめ）

::: tip なぜ VCC / ALCOM がおすすめ？
アップデートのたびにファイルを入れ直さなくてよくなります。新しいバージョンが出たら「更新」を押すだけ！
:::

1. 商品に同梱されている「**VCCに追加**」ショートカットを開く
   （<https://lemoneru.github.io/vpm-repos/> から「Add to VCC」でもOK）
2. VCC / ALCOM にリポジトリ「LEMONERU」を追加するか聞かれるので、承認する
3. プロジェクトの「Manage Project」で「**Avatar Blink Fix**」を追加する
4. Unity でプロジェクトを開けば、もう使える状態です

## unitypackage で導入する

VCC / ALCOM を使わない場合向けに、unitypackage も同梱しています。プロジェクトにインポートすればそのまま使えます。
ただしアップデートのたびに入れ直しが必要になるので、特別な事情がなければ VCC / ALCOM のほうが楽です。

## 解除キーのインポート（ご購入者向け）

入れただけの状態では、無料の**トライアル版**として動きます（自動選択された1つの BlendShape だけ修正できます）。

ご購入者は、同梱の**解除キー（unitypackage）**をプロジェクトに1回インポートしてください。

- **同じ PC の全プロジェクトでまとめて解除されます。** プロジェクトごとの作業はいりません
- 解除できると「コンプリート版になりました」と出ます
- アップデート後も、解除キーの入れ直しは不要です

::: details トライアル版から切り替えるとき、入れ直しは必要？
不要です。トライアル版の上から解除キーをインポートするだけで、残骸なくそのまま製品版になります。
:::

## 2.x からのアップデート

- 2.x をご購入済みの方は、追加料金なしでそのまま 3.0 を使えます
- **2.x で修正済みのアバターもそのまま使い続けられます。** 3.0 を入れても壊れません
  （修正済みアバターに右クリック修正をかけようとすると、ちゃんと検知して案内が出ます）
- 古い 2.x のファイルが残っていると、起動時に「旧本体を削除」の案内が出ます。削除しても、生成済みのデータやプリセットの記録は残るので安心してください
