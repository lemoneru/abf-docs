# 実際の修正の流れ

「結局どの順番でやればいいの？」に答えるページです。
表情改変から、表情Animationの確認、アップロード、ゲーム内で見るところまで、通しの流れをまとめました。

> **① 表情改変 → ② 自動修正 → ③ プレビュー → ④ 表情Animationを確認 → ⑤ アップロード → ⑥ ゲーム内で確認**

各ステップのくわしい話は、それぞれのページへリンクしてあります。

::: tip まだ入れていない方へ
先に [VCC / ALCOM に追加](/add) でツールを入れてください。**入れただけの状態で無料版として使えます。**
:::

## ① 表情改変を先に終わらせる

Avatar Blink Fix は、修正を押した時点の BlendShape の値を覚えて、そこから修正の中身を組み立てます。
なので、**表情改変を終わらせてから修正する**のがいちばん素直な流れです。

改変の途中で修正しても問題ありませんが、そのあと改変を足したときは、下の「あとから表情改変をやり直すとき」の操作が必要になります。

## ② アバターを右クリック →「自動修正（推奨）」

ヒエラルキーでアバターを右クリックして、「**Avatar Blink Fix**」→「**自動修正（推奨）**」を選びます。

![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

「まばたきの修正を設定しました」と出れば、設定は完了です。
アバターの下に「Avatar Blink Fix (NDMF)」というオブジェクトが追加され、設定はすべてこの子が持ちます。

→ くわしくは [自動修正（推奨）](/guide/auto-fix)

::: warning 「自動修正（推奨）」がグレーで押せないとき
そのアバター用の Auto Fix プリセットが用意されていない場合、メニューがグレーになって押せません。
直したい BlendShape を自分で選べば、同じように修正できます。
→ [手動修正（プリセットが無いアバター）](/guide/manual-fix)
:::

## ③ プレビューで修正後の顔を見る

自動修正を押すとプレビューが自動でONになるので、シーン上のアバターがそのまま修正後の顔になります。
思ったとおりの形になっているか、この時点で目で確かめられます。

インスペクタのボタンが赤い「**プレビューを終了**」になっていれば、プレビューONの状態です。

![修正後のインスペクタ。検出数の行と「表情を再読み込み」「プレビューを終了」ボタンが並ぶ](/images/easy-normal.png)

→ くわしくは [自動修正: その場で修正後の顔を確認できます](/guide/auto-fix#その場で修正後の顔を確認できます)

## 「表情アニメーションとの競合」と出たとき

この案内が出なければ、このステップは飛ばして大丈夫です。

表情アニメーションが、修正対象の BlendShape を動かしているのを見つけると、インスペクタに黄色い案内と「**ベイクモードに切り替える**」ボタンが出ます。
この案内が出たら、アップロード前に次の④を確認してください。表情Animationを編集するか、そのまま使うかで進め方が変わります。

100 を超える値やマイナス値（限界突破）が検出された場合は、ベイクモードへ切り替えてください。通常モードでは、その値をそのまま再現できません。
アニメーション側で顔が破綻している場合も、ベイクモードで軽減できる可能性があります。

→ くわしくは [ベイクモード](/guide/bake) ／ [通常モードとの違い](/guide/bake-vs-normal)

## ④ 表情Animationの扱いを決める

アップロード前に、表情Animationを変更するかどうかを確認します。

### FaceEmoなどで表情Animationも変更する場合

表情改変に合わせて表情Animationも変更する場合は、FaceEmoなどの表情改変ツールを使うか、Animationファイルを手動で編集します。

::: warning 値を0で固定している項目は削除してください
Avatar Blink Fixで修正したBlendShapeを値0で固定するカーブが残っていると、修正後のBlendShapeと競合することがあります。該当する項目は、表情Animationから削除してください。
:::

### 元から入っている表情Animationをそのまま使う場合

FaceEmoなどの表情改変ツールを使わず、アバターに元から入っている表情Animationのままアップロードする場合は、[ベイクモード](/guide/bake)がおすすめです。

ベイクモードなら、上に書いた0固定カーブの削除は必要ありません。

## ⑤ いつもどおりアップロードする

特別な操作はいりません。VRChat SDK からいつもどおりアップロードすれば、修正が適用された状態でアバターが上がります。

プレビューを終了していても、アップロード時にはきちんと修正が入ります（→ [仕組み](/guide/auto-fix#その場で修正後の顔を確認できます)）。

## ⑥ ゲーム内で確認する

VRChat に入って、まばたきと表情を動かしてみてください。問題がなければ、これで完了です。

目の動きがおかしいときは、表情Animationと競合している可能性があります。④の0固定カーブが残っていないか確認するか、[ベイクモード](/guide/bake)を試してみてください。

## あとから表情改変をやり直すとき

1. インスペクタの「**プレビューを終了**」を押す（プレビュー中のまま改変すると、意図しない結果になることがあります）
2. 表情改変をやり直す
3. 「**表情を再読み込み**」を押して、改変後の状態で覚え直させる

表情改変ツールで表情Animationを作成・変更するときは、逆にプレビューをONにしたまま進めてください。

→ くわしくは [自動修正: あとから表情改変をやり直すとき](/guide/auto-fix#あとから表情改変をやり直すとき)

やめたくなったら、追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除してください。元のメッシュは書き換えていません。

## こんなときは

| 状況 | 行き先 |
|---|---|
| 「表情アニメーションとの競合」と表示された | アップロード前に、上の「④ 表情Animationの扱いを決める」を確認 |
| 表情Animationを編集せず、そのまま使いたい | [ベイクモード](/guide/bake)がおすすめ |
| ゲーム内で表情を動かすと目の動きがおかしい | [ベイクモード](/guide/bake) |
| アニメーションのせいで顔が破綻している | [ベイクモード](/guide/bake)（破綻を軽減できる場合があります） |
| 100 を超える値やマイナス値で改変している | [ベイクモード](/guide/bake) |
| 「自動修正（推奨）」がグレーで押せない | [手動修正](/guide/manual-fix) |
| NDMF を入れていない／2.x と同じ操作で使いたい | [メッシュ入れ替え式](/guide/meshswap) |
| Avatar Mouth Fix と一緒に使いたい | [メッシュ入れ替え式の通常修正](/guide/meshswap#avatar-mouth-fix-と併用する場合) |
| フェイストラッキングを使っている | [フェイストラッキングを使う方へ](/guide/face-tracking) |
| BlendShape を追加する改変と一緒に使っている | [BlendShape を追加する改変と一緒に使うとき](/guide/added-blendshapes) |
| MMD用・フェイストラッキング用の BlendShape も直したい | [無料版と有料版の違い](/guide/editions) |
| そのほか、うまくいかない | [よくある質問（FAQ）](/faq) |
