# 実際の修正の流れ

「**結局どの順番でやればいいの？**」がひと目で分かるページです。
表情改変から、アップロードしてゲーム内で見るところまで、通しの流れをまとめました。

> **① 表情改変 → ② 右クリックで自動修正 → ③ プレビューで確認 → ④ アップロード → ⑤ ゲーム内で確認**

各ステップのくわしい話は、それぞれのページへリンクしてあります。

::: tip まだ入れていない方へ
先に [VCC / ALCOM に追加](/add) でツールを入れてください。**入れただけの状態で無料版として使えます。**
:::

## ① 表情改変を先に終わらせる

Avatar Blink Fix は、**修正を押した時点の BlendShape の値**を覚えて、そこから修正の中身を組み立てます。
なので、**表情改変を終わらせてから修正する**のがいちばん素直な流れです。

改変の途中で修正しても問題ありませんが、そのあと改変を足したときは ⑥ の「表情を再読み込み」が必要になります。

## ② アバターを右クリック →「自動修正（推奨）」

ヒエラルキーでアバターを右クリックして、「**Avatar Blink Fix**」→「**自動修正（推奨）**」を選びます。

![右クリックメニューの「Avatar Blink Fix」サブメニュー](/images/context-menu.png)

「まばたきの修正を設定しました」と出れば、設定は完了です。
アバターの下に「Avatar Blink Fix (NDMF)」というオブジェクトが追加され、設定はすべてこの子が持ちます。

→ くわしくは [自動修正（推奨）](/guide/auto-fix)

::: warning プリセットが無い／合わないと表示されたとき
そのアバター用の Auto Fix プリセットが用意されていない場合です。
直したい BlendShape を自分で選べば、同じように修正できます。
→ [手動修正（プリセットが無いアバター）](/guide/manual-fix)
:::

## ③ プレビューで修正後の顔を見る

自動修正を押すと**プレビューが自動でONになる**ので、シーン上のアバターがそのまま修正後の顔になります。
思ったとおりの形になっているか、**この時点で目で確かめられます**。

インスペクタのボタンが赤い「**プレビューを終了**」になっていれば、プレビューONの状態です。

![修正後のインスペクタ。検出数の行と「表情を再読み込み」「プレビューを終了」ボタンが並ぶ](/images/easy-normal.png)

→ くわしくは [自動修正: その場で修正後の顔を確認できます](/guide/auto-fix#その場で修正後の顔を確認できます)

## ④ 「表情アニメーションとの競合」と出たら、ベイクモードへ

**この案内が出なければ、このステップは飛ばして大丈夫です。**

表情アニメーションが、修正対象の BlendShape を動かしているのを見つけると、インスペクタに黄色い案内と「**ベイクモードに切り替える**」ボタンが出ます。
そのままだと、ゲーム内で表情を動かしたときに目の動きがおかしくなることがあるので、ボタンを押して切り替えてください。設定はそのまま引き継がれます。

**100 を超える値やマイナス値**（限界突破）で改変しているときも、ベイクモードが向いています。
アニメーション側で顔が破綻してしまっている場合も、ベイクモードなら**破綻を軽減できます**。

→ くわしくは [ベイクモード](/guide/bake)

## ⑤ いつもどおりアップロードする

**特別な操作はいりません。** VRChat SDK からいつもどおりアップロードすれば、**修正が適用された状態で**アバターが上がります。

プレビューを終了していても、アップロード時にはきちんと修正が入ります。
元のメッシュは書き換えていないので、修正はアップロード（ビルド）のときにだけ適用されます。

## ⑥ ゲーム内で確認する

VRChat に入って、**まばたきと表情を動かしてみてください**。問題がなければ、これで完了です。

目の動きがおかしいときは、表情アニメーションと競合している可能性があります。④ の[ベイクモード](/guide/bake)を試してみてください。

## ⑦ 直したくなったら、戻ってやり直す

表情改変をやり直したいときは、この順番でどうぞ。

1. インスペクタの「**プレビューを終了**」を押す
2. 表情改変をやり直す
3. 「**表情を再読み込み**」を押して、改変後の状態で覚え直させる

::: warning プレビューを終了してから改変してください
プレビュー中は修正済みのメッシュに差し替わって表示されているため、その状態のまま改変すると意図しない結果になることがあります。
:::

→ くわしくは [自動修正: あとから表情改変をやり直すとき](/guide/auto-fix#あとから表情改変をやり直すとき)

**やめたくなったら**、追加された「Avatar Blink Fix (NDMF)」オブジェクトを削除するだけです。メッシュは触っていないので、完全に元通りになります。

## こんなときは

| 状況 | 行き先 |
|---|---|
| 「表情アニメーションとの競合」と表示された | **[ベイクモード](/guide/bake)** |
| ゲーム内で表情を動かすと目の動きがおかしい | **[ベイクモード](/guide/bake)** |
| アニメーションのせいで顔が破綻している | **[ベイクモード](/guide/bake)**（破綻を軽減できます） |
| 100 を超える値やマイナス値で改変している | **[ベイクモード](/guide/bake)** |
| プリセットが無い／合わないと表示された | [手動修正](/guide/manual-fix) |
| NDMF を入れていない／2.x と同じ操作で使いたい | [メッシュ入れ替え式](/guide/meshswap) |
| MMD用・フェイストラッキング用の BlendShape も直したい | [無料版と有料版の違い](/guide/editions) |
| そのほか、うまくいかない | [よくある質問（FAQ）](/faq) |

::: tip 迷ったらベイクモード
表情アニメーションを使っているアバターなら、**ベイクモードのほうが崩れにくい**です。
通常モードで問題が出たら、まずベイクモードを試してみてください。設定はそのまま引き継がれます。
:::
