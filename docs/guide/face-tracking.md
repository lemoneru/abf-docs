# フェイストラッキングを使う方へ

フェイストラッキング（FT）対応のアバターでも、Avatar Blink Fix はそのまま使えます。
**多くの場合、はじめの設定のままで大丈夫です。**

このページは、ゲーム内で FT の目の閉じ方がおかしいときや、設定の意味を知りたいときに読んでください。

::: tip このページは有料版（コンプリート版）の話です
FT 用 BlendShape の修正はコンプリート版の機能です。無料版では、ここで説明するセクションもトグルも表示されません。
→ [無料版と有料版の違い](/guide/editions)
:::

## まず答え

| こういうとき | どうする |
|---|---|
| [自動修正（推奨）](/guide/auto-fix)で、とくに問題が出ていない | **そのまま**（「含めない」のまま）で大丈夫です |
| ゲーム内で FT の目閉じが崩れる・目が埋まる | 「**修正に含める**」に切り替えて試してください |
| [ベイクモード](/guide/bake)を使う | **はじめから「含める」**になっています。そのままで大丈夫です |

切り替えても壊れません。**両方ためして、良かったほうを残してください。**

## 切り替える場所

インスペクタの「**フェイストラッキングのBlendShape**」にある、［**修正に含める**］［**含めない**］のボタンで切り替えます。

詳細設定を開いている場合は「**フェイストラッキング用BlendShapeも修正する**」のチェックが同じ役割です。どちらを操作しても結果は同じです。

## ツールが出す案内と、そのときの選び方

FT 用の BlendShape を見つけると、ツールが状況に合わせて案内を出します。**書いてあるとおりに選べば大丈夫です。**

| ツールに出る文章 | 意味 | おすすめ |
|---|---|---|
| フェイストラッキング用のBlendShapeを検出しました。FT側で対応済みの場合は「含めない」のままで大丈夫です。 | FT 用の BlendShape が見つかった | **含めない**（症状が出たら切り替え） |
| FT側のアニメーションがフェイストラッキング用のBlendShapeを制御しています。FT側で修正済みの可能性が高いため、「含めない」がおすすめです。 | FT アドオン側がすでに面倒を見ている | **含めない** |
| ベイクモードでは「修正に含める」がおすすめです。 | ベイクモードで設定した | **含める**（はじめからそうなっています） |

## FT用と判断する条件

顔のメッシュに **`EyeClosedLeft` / `EyeClosedRight`**（フェイストラッキングで広く使われている名前）があるかどうかを見ています。
この名前が無いアバターでは、FT のセクションはそもそも表示されません。

アバター専用の Auto Fix プリセットに FT 用の BlendShape が登録されている場合は、名前が違っていても対象になります。

## なぜ通常モードとベイクモードで逆なのか

FT 対応アバターの多くは、**表情改変で動かした BlendShape を、FT 側のアニメーションで 0 に戻す**作りになっています。

- **通常モード**では、この 0 に戻す動きがそのまま働きます。こちらで直すと二重になるので、はじめは「**含めない**」です
- **ベイクモード**では、改変した状態がメッシュそのものに焼き付きます。焼き付いたあとに 0 に戻しても顔は戻らないので、こちら側で直しておく必要があります。だからはじめから「**含める**」です

→ 2つのモードの違い全体は [ベイクモードと通常モード、何が違うの？](/guide/bake-vs-normal)

## 直せる範囲

::: warning 直すのはアバターの BlendShape までです
Avatar Blink Fix が作り直すのは、**アバターが持っている BlendShape** です。
FT アドオン側のアニメーションや設定までは変更しません。
:::

- ✅ 表情改変で崩れた FT 用の目閉じ BlendShape を作り直す
- ❌ FT アドオンのアニメーションの中身を書き換える
- ❌ Web カメラのまばたき検知による崩れ → [FAQ](/faq#webcam)

「修正に含める」にしても症状が残る場合は、**FT アドオン側の設定**をご確認ください。

## 表情改変をやり直したとき

FT 用の BlendShape も、ほかと同じように覚え直しが必要です。「**表情を再読み込み**」を押してください。

→ 手順は [自動修正: あとから表情改変をやり直すとき](/guide/auto-fix#あとから表情改変をやり直すとき)
