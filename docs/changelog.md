# 更新履歴

VCC / ALCOM で導入している場合、新しいバージョンは「更新」ボタンを押すだけ。有料版のファイルを入れ直す必要もありません。

## 3.0.24（2026-10-23）

- おつかれ天使、ルシアン、エルエルのプリセットを追加しました。
- 追加シェイプキー用のプリセットを追加しました（Lapwing「100人に聞いた！追加シェイプキー」、水瀬「プラスシェイプキー」）。追加シェイプキーを入れていないアバターでは、これまでどおり通常のプリセットが選ばれます。

## 3.0.23（2026-10-11）

- アバターを複数置いたシーンで、Unityエディタが常にカクつく問題を修正しました。
- プレビュー中にPrefabへ上書き保存（Apply）して保存先の顔メッシュが空になったとき、「顔のメッシュが消えました」の［戻す］を押すだけで、元の顔メッシュとベイク対象の値を戻せるようにしました。Ctrl+Zで取り消せます。
- 表情の[バックアップ](/faq#expression-backup)を、プレビューを始める直前と、顔や設定を変えて2秒後にも自動で保存するようにしました。

## 3.0.22（2026-10-10）

- たゆた、Lowtus（通常スタイル）のプリセットを追加しました。
- Mennoのプリセットを、修正後に目の形が変わることがある問題を直した版へ更新しました。

## 3.0.21（2026-10-05）

- アップロード時にFT用BlendShapeを追加するタイプのFTアドオンで、ベイクモードの自動セットアップが［修正に含める］をONにしない問題を修正しました。すでにセットアップ済みのアバターは、[フェイストラッキングの設定](/guide/face-tracking)で［修正に含める］を選んでください。
- ライラパイライト、ポポちゃん、ミシェラのプリセットを追加しました。

## 3.0.20（2026-10-03）

- もなとの一部の左ウインクで、開いている側の目の改変が戻る問題に対応しました。
- プリセットごとに、ウインクの左右判定と補正する側を指定できるようにしました。設定のない既存のプリセットは、これまでと同じ判定で動きます。

新しい左右判定の設定を含むプリセットと、この版で保存した設定ファイルは、3.0.20以降で使用してください。

## 3.0.0 — 3.0 の大きな変更

### 大きな変更

- **非破壊化**: アバターを右クリック →「自動修正（推奨）」だけで完了する方式になりました（NDMF 対応）。メッシュを書き換えず、アップロード時に自動で修正が適用されます。追加されたオブジェクトを削除すればいつでも元通りです
- 今までのウィンドウ（2.x と同じ方式）も「**メッシュ入れ替え式**」としてそのまま残っています。NDMF を入れていない環境や、他ツールと相性が出た場合の回避経路としてご利用いただけます
- 2.x で修正済みのアバターはそのまま使い続けられます。3.0 を上書きインポートしても壊れません（右クリック修正しようとした場合は検知して案内を出します）

### 新機能

- **競合の自動チェック**: 表情アニメーションが修正対象の BlendShape を操作している場合に検知して案内し、ベイクモードへの切り替えを提案します
- **ベイクモードも非破壊に**: 改変した表情を基礎メッシュへ焼き込む処理もビルド時に自動適用されます
- BlendShape の**限界突破**（100 超・マイナス値）に対応しました
- **フェイストラッキング (FT)** アバターの目閉じ BlendShape を検出し、修正対象に含めるか選べるようになりました
- **微調整設定の書き出し / 読み込み**: 設定を JSON に保存し、Blender で作り直したアバターにも読み込めます
- **Animation 合成**で、PhysBone やオブジェクトの ON/OFF など BlendShape 以外のキーも消えずに引き継がれるようになりました
- **保存データの管理**: ツールが保存した記録（バックアップ等）を一覧で確認・削除できるようになりました
- **サポート情報のコピー**: 問い合わせ時に貼り付けるだけで状況が伝わる診断コードを出力できます
- **VCC / ALCOM 対応**（VPM 配布）: 更新のたびに入れ直す必要がなくなりました
- 対応言語: 日本語 / English / 한국어 / 中文

### トライアル版

- トライアル版を一新し、製品版と同じ 3.0 の操作感（右クリック導線・プレビュー・復元）で試せるようになりました。修正できるのは自動選択された1つの BlendShape のみです
- トライアル版の上から製品版（解除キー）を導入するだけで、残骸なくそのまま製品版になります

### 修正・改善

- エラーメッセージを「原因 + 次にすること」が分かる形へ全面的に見直しました
- プリセット未導入時は、エラーではなく案内を表示するようにしました
- 危険な BlendShape（顔全体が変わるもの等）の警告を分かりやすくしました

### 既知の注意点

- NDMF のプレビューが停止すると修正が見えなくなることがあります。Unity を再起動すると回復します
- プレビューがONのときは、シーン上でも修正後の見た目を確認できます。OFFでもアップロード時には修正が反映されます
