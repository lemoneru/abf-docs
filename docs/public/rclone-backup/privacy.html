rclone backup プライバシーポリシー

最終更新: 2026年10月5日

「rclone backup」（以下「本設定」）は、LEMONERU が本人の Google アカウントだけで使う個人用の設定です。

アクセスする Google のデータ

本設定は、本人の Google ドライブ上のファイルとフォルダ（一覧・内容・作成・更新）にアクセスします。

データの使い方

  • 本人の PC から本人の Google ドライブへファイルをバックアップするため
  • 本人の Google ドライブの指定フォルダから本人の PC へファイルをコピーするため

保存と共有

  • 認証情報（トークン）とコピーしたファイルは、本人の PC にだけ保存します。
  • Google のデータを第三者へ販売・提供・共有しません。広告や分析には使いません。
  • 本設定の運営者が管理するサーバーはなく、データは本人の PC と本人の Google アカウントの間でのみやり取りされます。

アクセスの取り消し

Google アカウントのサードパーティ接続から、いつでもアクセスを取り消せます。

Google API Services User Data Policy

本設定による Google API から受け取った情報の使用は、限定的使用の要件を含む Google API Services User Data Policy に従います。

Privacy Policy (English)

"rclone backup" is a personal configuration used only by its owner (LEMONERU) with their own Google account. It accesses files and folders in the owner's Google Drive solely to back up files from the owner's PC and to copy files from a designated Drive folder to the owner's PC. Tokens and copied files are stored only on the owner's PC. Google user data is not sold, transferred, or shared with any third party and is not used for advertising or analytics. There is no server operated for this configuration. Access can be revoked at any time at Google Account third-party connections. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: https://github.com/lemoneru
