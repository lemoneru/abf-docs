# よくある質問（FAQ）

**よく来る質問から順に**並べてあります。症状で探してみてください。ここに無ければ[お問い合わせ](#contact)へどうぞ。

## 🔝 まずはここ！ 特によくある質問

### 修正したあと、表情改変をやり直したい {#redo-expression}

**先に「プレビューを終了」を押してから**改変してください。プレビュー中は修正済みのメッシュに差し替わっているので、そのまま改変すると意図しない結果になることがあります。

1. インスペクタの「**プレビューを終了**」を押す
2. 表情改変をやり直す
3. 「**表情を再読み込み**」を押す（変更後の状態で記録し直します）

「Avatar Blink Fix (NDMF)」オブジェクトごと削除して、もう一度右クリック →「自動修正（推奨）」でも同じです。

### プレビューを終了したら、顔が元に戻ってしまった {#preview-off}

**それで正常です！** [自動修正](/guide/auto-fix)・[ベイクモード](/guide/bake)は非破壊方式なので、実際の修正は**アップロード（ビルド）のときに適用されます**。プレビューを終了していても、アップロードすれば修正が適用された状態で上がります。

シーン上でもう一度確かめたいときは、インスペクタの「修正後をプレビュー」を押してください。

### 修正したのに、シーン上の見た目が変わらない {#no-visual-change}

自動修正を押すとプレビューが自動でONになるので、ふつうはその場で修正後の顔になります。変わらないときは、次を確認してください。

- インスペクタのボタンが「**修正後をプレビュー**」（＝プレビューOFF）になっていませんか？ 押すとONになります
- NDMF のプレビューが止まっていることがあります。**Unity を再起動**すると回復します

### 無料版で直せない／修正対象が出てこない {#trial}

無料版で直せるのは、**自動で選ばれたまばたき用の BlendShape 1つ**です。

また、アバターによってはその対象になる BlendShape が見つからず、お試しできないことがあります。MMD 用 BlendShape やフェイストラッキング用 BlendShape の修正も有料版の機能です。

→ [無料版と有料版の違い](/guide/editions) で、どちらを使えばいいか比較できます。

### 「目の変形が見つかりません」と出る／一覧に BlendShape が出ない {#no-modification}

顔のメッシュ（Body）の **BlendShape の値を変えていない**のが原因です。

このツールが直すのは「BlendShape の値を変えて行った表情改変」です。表情作成ツールでアニメーションの差分を作っただけだと、メッシュ側の値は変わっていないので「直すものがない＝修正不要」と判断されます。

BlendShape の値を変えて改変したら、そのあとで「表情を再読み込み」（ウィンドウなら再検出）を押してください。

### 対応アバターなのに「プリセットが無い／合わない」と出る {#preset-missing}

- **VCC / ALCOM で導入している場合**: ツールを最新版に**更新**してみてください。プリセットは本体の更新で追加されます
- **unitypackage で導入している場合**: 商品ページから最新版をダウンロードして、インポートし直してください
- アバター側のアップデートでプリセットが合わなくなっていることもあります。「手動修正」でも対応できますし、[ご連絡](#contact)いただければプリセットの更新を検討します

### 表情改変に使った BlendShape にチェックを入れられない {#used-in-expression}

仕様です。表情に使っている BlendShape を修正してしまうと、**せっかく作った表情のほうが変わってしまう**ためです。

- 3.0 では、こういうケースこそ[ベイクモード](/guide/bake)の出番です。表情をメッシュに焼き込んでから修正するので、表情を保ったまま直せます
- 従来の回避策として、左右分割の BlendShape（BlinkL / BlinkR など）を左右同じ値で表情に使い、元の BlendShape を 0 に戻す方法もあります

### ゲーム内でまばたきすると目がおかしい／目が閉じない {#broken-in-game}

多い順に、次の3つをチェックしてみてください。

1. **表情アニメーションとの競合** — インスペクタに黄色い案内が出ていたら「ベイクモードに切り替える」を押すだけ（→ [ベイクモード](/guide/bake)）
2. **表情アニメーション内の 0 固定キー** — 既存の表情アニメーションに、修正済みの BlendShape が値 0 で入っていると競合します。アニメーションファイルから該当の項目を削除してください
3. **リセット用 BlendShape** — 修正後、顔メッシュの一覧のいちばん下にある左右リセット用の BlendShape が 100 になっていると、片目だけ元に戻ることがあります。0 にしてください

## 修正の仕上がりについて

### まばたきするとまぶた・まつ毛が不自然に動く {#unnatural-eyelid}

手動修正で、**対象にしなくていい BlendShape までチェックが入っている**かもしれません。

修正対象は「完全に目を閉じる」BlendShape だけに絞るのがコツです。まつ毛の位置調整・半目・目のサイズ変更などを入れると、まばたきが不自然になります。

### 100 を超える値やマイナス値（限界突破）で改変している {#over-range}

3.0 で対応しました！ 限界突破した値が含まれる場合は[ベイクモード](/guide/bake)での修正になります（案内が出ます）。

### 2.x で修正済みのアバターはどうなる？ {#from-2x}

そのまま使い続けられます。3.0 を入れても壊れません。修正済みアバターに右クリック修正をかけようとした場合も、検知して案内が出るので安心してください。

3.0 で変わったことのまとめは [2.x をお使いの方へ](/guide/from-2x) をどうぞ。

## フェイストラッキング（FT）

### FT 対応アバターでも使える？ {#face-tracking}

使えます。FT 用の目閉じ BlendShape（EyeClosed 系など）を自動で見つけて、修正に含めるかどうか選べます。

- **通常モードでは、はじめは「含めない」**です。FT 対応アバターは FT 側の仕組みで目閉じが調整されていることが多いためです
- **ベイクモードでは、はじめから「含める」**です（理由は[ベイクモードのページ](/guide/bake#フェイストラッキング-ft-アバターの場合)で）
- ゲーム内で FT の目閉じが崩れるときは「含める」に切り替えて試してみてください

### Web カメラのまばたき検知で目が崩れる {#webcam}

Web カメラのトラッキングはアバター側の制御を飛び越えて BlendShape を動かすため、ツール側での対応が難しい部分です。VRChat の設定（Avatar Descriptor 側）で Web カメラの瞬きを止めるのが現実的な回避策になります。

## トラブル

### プレビューが効かなくなった／修正が見えなくなった {#preview-stuck}

NDMF のプレビューが止まると、修正結果が見えなくなることがあります。**Unity を再起動すれば直ります。**

### 古い記録が原因で修正がうまくいかない {#stale-data}

過去の修正の記録（バックアップ等）が残っていて悪さをすることがあります。ツールの「**保存データの管理**」から、該当アバターの記録を削除してやり直してみてください。

### アバターを複製・名前変更したら「修正済み」扱いになる／エラーが出る {#copied-avatar}

メッシュ入れ替え式では、修正の記録を**アバター名ごと**に持っています。修正済みアバターを複製したり Prefab の名前を変えたりすると、記録と合わなくなって二重修正防止が働くことがあります。

名前を変えたときは、「保存データの管理」から古い記録を削除してから、もう一度修正してください。

## その他

### PCに何か保存されますか？　外部と通信しますか？ {#privacy}

**外部への通信は一切行いません。** ライセンス確認のためのサーバー通信もありません。

PCに保存されるのは、次のUnityの EditorPrefs だけです。

| 保存されるもの | キー名 |
|---|---|
| 解除キーの値（有料版にしたとき） | `AvatarBlinkFix_UnlockSecret` |
| 表示言語 | `AvatarBlinkFix_Language` |
| 直近のエラー（サポート情報に載せるため） | `AvatarBlinkFix_RecentErrors` |
| 「新機能のお知らせ」を表示したか | `ABF_WhatsNew_3_0_Shown` |
| インスペクタの詳細設定を開いているか | `ABF_ShowDetailSettings` |

消したいときは、ツールの **[トライアル版に戻す]** を押してください（このPCの保存が消えます）。
手で消す場合の保存場所は、同梱の `README.md` に書いてあります。
