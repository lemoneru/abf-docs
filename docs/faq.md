## 導入・トライアル・プリセット

### 修正したのに、シーン上のアバターの見た目が変わらない {#no-visual-change}

**正常です。** [自動修正](/guide/auto-fix)・[ベイクモード](/guide/bake)は非破壊方式のため、修正は**アップロード（ビルド）時に適用されます**。シーン上で確かめたいときは、インスペクタの「修正後をプレビュー」を押してください。

### トライアル版でできることは？ {#trial}

ツールを導入しただけの無料状態がトライアル版です。**自動選択された1つの BlendShape のみ**修正できます。操作は製品版と同じです。

アバターによっては、トライアル版が対象にできる BlendShape が存在せず、お試しできないことがあります。その場合はコンプリート版をご検討ください（コンプリート版は任意の BlendShape を修正できます）。

MMD 用 BlendShape の修正など、トライアル版の範囲を超える機能もコンプリート版が必要です。

### 対応アバターなのに「プリセットが無い／合わない」と表示される {#preset-missing}

- **VCC / ALCOM で導入している場合**: ツールを最新版に**更新**してください。プリセットは本体の更新で追加されます
- **unitypackage で導入している場合**: 商品ページから最新版をダウンロードし、インポートし直してください
- アバター自体のアップデートでプリセットが合わなくなっている場合もあります。その場合は「手動修正」でも対応できますし、[お問い合わせ](#contact)いただければプリセットの更新を検討します

### 2.x で修正済みのアバターはどうなる？ {#from-2x}

そのまま使い続けられます。3.0 を導入しても壊れません。修正済みアバターに右クリック修正をかけようとした場合は、検知して案内が出ます。

## 修正がうまくいかない

### 「目の変形が見つかりません」と表示される／一覧に BlendShape が出ない {#no-modification}

顔のメッシュ（Body）の **BlendShape の値を変更していない**ことが原因です。

このツールは「BlendShape の値を変えて行った表情改変」を修正するものです。表情作成ツールでアニメーションの差分を作っただけでは、メッシュ側の値は変わっていないため、修正対象がない＝修正不要と判断されます。

顔の BlendShape 値を変えて改変している場合は、値を変更したあとに「表情を再読み込み」（ウィンドウの場合は再検出）を押してください。

### 表情改変に使った BlendShape にチェックを入れられない {#used-in-expression}

仕様です。表情に使っている BlendShape を修正すると、**作った表情そのものが変わってしまう**ためです。

- 3.0 では、こうしたケースは[ベイクモード](/guide/bake)で対応できます（表情をメッシュに焼き込んでから修正するため、表情を保ったまま修正できます）
- 従来の回避策として、左右分割された BlendShape（BlinkL / BlinkR など）を左右同じ値で表情に使い、元の BlendShape を 0 に戻す方法もあります

### ゲーム内でまばたきすると目の動きがおかしい／目が閉じない {#broken-in-game}

多い順に、次の3つを確認してください。

1. **表情アニメーションとの競合** — インスペクタに黄色い案内が出ていたら、「ベイクモードに切り替える」を押してください（→ [ベイクモード](/guide/bake)）
2. **表情アニメーション内の 0 固定キー** — 既存の表情アニメーションに、修正済みの BlendShape が値 0 で焼き込まれていると競合します。アニメーションファイルから該当の項目を削除してください
3. **リセット用 BlendShape** — 修正後、顔メッシュの一覧の最後にある左右リセット用の BlendShape が 100 になっていると、片目だけ元に戻ることがあります。0 に戻してください

### まばたきするとまぶた・まつ毛が不自然に動く {#unnatural-eyelid}

手動修正で、**対象にしてはいけない BlendShape にチェックが入っている**可能性があります。

修正対象には「完全に目を閉じる」BlendShape だけを選んでください。まつ毛の位置調整・半目・目のサイズ変更などを含めると、まばたきが不自然になります。

### 100 を超える値やマイナス値（限界突破）を使った改変 {#over-range}

3.0 で対応しました。限界突破した値が含まれる場合は、[ベイクモード](/guide/bake)での修正になります（案内が表示されます）。

## フェイストラッキング（FT）

### FT 対応アバターでも使える？ {#face-tracking}

使えます。FT 用の目閉じ BlendShape（EyeClosed 系など）を自動検出し、修正に含めるかどうか選べます。

- **通常モードでは既定で「含めない」**です。FT 対応アバターは FT 側の仕組みで目閉じが調整されていることが多いためです
- **ベイクモードでは既定で「含める」**です（理由は[ベイクモードのページ](/guide/bake#フェイストラッキング-ft-アバターの場合)を参照）
- ゲーム内で FT の目閉じが崩れる場合は、「含める」に切り替えて試してください

### Web カメラのまばたき検知で目が崩れる {#webcam}

Web カメラによるトラッキングは、アバター側の制御を超えて BlendShape を強制的に動かすため、ツールでの対応が困難です。VRChat の設定（Avatar Descriptor 側）で Web カメラによる瞬きを止めるのが現実的な回避策です。

## トラブル

### プレビューが効かなくなった／修正が見えなくなった {#preview-stuck}

NDMF のプレビューが停止すると、修正結果が見えなくなることがあります。**Unity を再起動すると回復します。**

### 古い記録が原因で修正がうまくいかない {#stale-data}

過去の修正の記録（バックアップ等）が残っていて悪さをすることがあります。ツールの「**保存データの管理**」から該当アバターの記録を削除して、やり直してください。

### アバターを複製・名前変更したら「修正済み」扱いになる／エラーが出る {#copied-avatar}

メッシュ入れ替え式では、修正の記録を**アバター名ごと**に持っています。修正済みアバターを複製したり Prefab の名前を変えたりすると、記録との照合で二重修正防止が働くことがあります。

名前を変えた場合は、「保存データの管理」から古い記録を削除してから、再度修正してください。
