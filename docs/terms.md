# 利用規約

最終更新: 2026年8月27日

Avatar Blink Fix（以下「本ツール」）をご利用になる前に、この規約をお読みください。
**本ツールを導入・使用された時点で、この規約に同意したものとみなします。**

## 1. 本ツールについて

- 本ツールは、表情改変によって崩れた目のBlendShapeを修正する、VRChatアバター向けのUnityエディタ拡張です
- **無料版**と**有料版**があります（違いは → [無料版と有料版の違い](/guide/editions)）
- 有料版は [Avatar Blink Fix の販売ページ（BOOTH）](https://lemoneru.booth.pm/items/7074770) で販売しています

## 2. できること

- 本ツールを使ってアバターを制作・改変し、**VRChatなどで公開・配信していただけます**
- 本ツールで修正したアバターを使った**動画・配信・SNSへの投稿は自由**です
- 本ツールの**紹介・解説（動画・記事など）も自由**に行っていただけます
- ご自身の環境に合わせて設定を変えることは自由です

## 3. 禁止事項

- **本ツールおよび解除キーの再配布・販売・共有・自作発言**
- **無料版の機能制限や解除キーの照合を、改変・無効化して有料版相当の機能を利用すること。またその方法を公開・配布すること**
- **本ツールが生成したMeshデータの配布・販売・自作発言**
- 中傷・政治的・宗教的活動を目的とした使用
- 法令に違反する使用

## 4. 生成されたデータの扱い

- 本ツールが生成したMesh・Animationなどは、**元になったアバターの規約に従います**
- 元アバターの規約と本規約の内容が異なる場合は、**元アバターの規約が優先されます**
- 生成されたデータ単体での配布・販売はできません（「禁止事項」のとおり）

## 5. 解除キーについて

- 有料版の解除キーは、**ご購入者ご本人のみ**がご利用いただけます
- 解除キーの中身や、それに相当する情報を第三者へ渡さないでください
- 解除キーはご利用のPCのUnity（EditorPrefs）に保存されます。ツールの **[トライアル版に戻す]** からいつでも削除できます

## 6. 保存されるもの・外部通信について

**本ツールは外部への通信を一切行いません。** ライセンス確認のためのサーバー通信もありません。

PCに保存されるのは、次のUnityのEditorPrefsだけです。

| 保存されるもの | キー名 |
|---|---|
| 解除キーの値（解除キーを読み込んだとき） | `AvatarBlinkFix_UnlockSecret` |
| 表示言語 | `AvatarBlinkFix_Language` |
| 直近のエラー（サポート情報に載せるため） | `AvatarBlinkFix_RecentErrors` |
| 「新機能のお知らせ」を表示したか | `ABF_WhatsNew_3_0_Shown` |
| インスペクタの詳細設定を開いているか | `ABF_ShowDetailSettings` |

削除したいときは、ツールの **[トライアル版に戻す]** を押してください（このPCの保存が消えます）。
手で消す場合の保存場所は、同梱の `README.md` に記載しています。
