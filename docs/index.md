## Avatar Blink Fix とは

表情を改変していい顔ができたのに、ゲーム内でまばたきすると**目が突き抜ける・閉じきらない**——
Avatar Blink Fix は、その原因である目の BlendShape を自動で修正する Unity エディタ拡張です。
MMD ワールドで目が崩れる問題も直ります。

## 使い方は3通り

| 方式 | どんなとき使うか | ページ |
|---|---|---|
| **自動修正（推奨）** | まずはこれ。右クリック1回・非破壊 | [自動修正（推奨）](/guide/auto-fix) |
| **ベイクモード** | 表情アニメーションとの競合を指摘されたとき／ゲーム内で目の動きがおかしいとき | [ベイクモード](/guide/bake) |
| **メッシュ入れ替え式** | NDMF を入れていない環境／2.x と同じ操作で使いたいとき | [メッシュ入れ替え式](/guide/meshswap) |

## まずはお試し（トライアル版）

ツールを導入しただけの状態では、**無料のトライアル版**として動作します。
修正できるのは自動選択された1つの BlendShape のみですが、操作は製品版と同じです。
ご購入後は解除キーを1回インポートするだけで、そのまま製品版になります（→ [導入方法](/guide/install)）。
