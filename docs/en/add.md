# Add to VCC / ALCOM

::: danger Currently distributed to supporter-edition buyers only
For now, this repository is offered **only to those who purchased the supporter edition**.

🔑 **Without an unlock key, the tool does not run as the Complete Edition.**
You can still install it — it will run as the **free (trial) edition**.

The unlock key is available **from the BOOTH purchase page for supporter-edition buyers**.

⚠️ **2.x owners also need an unlock key for 3.0** (unlock keys are new in 3.0 and are not included in 2.x) → [Coming from 2.x](/en/guide/from-2x)

**The public release date will be announced on this page and on BOOTH once decided.** After that, everyone can use the repository.
:::

Installing via VCC / ALCOM means no more importing a unitypackage for every update. The Auto Fix presets are updated together with the tool.

<AgreeInstall />

::: details If VCC / ALCOM doesn't open automatically
In VCC / ALCOM, go to Settings → "Packages" → "Add Repository" and paste this URL:

```
https://lemoneru.github.io/vpm-repos/index.json
```

Buyers can also use the "**VCCに追加**" (Add to VCC) shortcut bundled with the product — it does the same thing.
:::

## After adding the repository

1. You'll be asked to add the "LEMONERU" repository — **approve it**
2. In your project's package management, find "**Avatar Blink Fix**" and **add it with the ＋ button**
   (typing "blink" in the search box gets you there fast)

   ![ALCOM package management screen showing the Avatar Blink Fix row and add button](/images/alcom-add-package.png)

3. Open the project in Unity and you're ready to go

Head over to [How to Use](/en/guide/workflow). **A fresh install runs as the free edition**, so you can try it before buying.

::: tip When a new version comes out
With the repository added, VCC / ALCOM shows an "**Update**" button on your project. One click and you're on the latest version — no files to re-import.
:::

## Upgrading to the Complete Edition

The paid edition is available on the [Avatar Blink Fix page on BOOTH](https://lemoneru.booth.pm/items/7074770).

After purchase, **import the included unlock key into a project once** and you're upgraded.
**Every project on that PC becomes the Complete Edition** — no per-project setup.

::: tip For 2.x owners
**Upgrading to 3.0 is free of charge.**

⚠️ However, **3.0 switched to an "unlock key" system** (in 2.x, the purchased files themselves were the full product).
You need an unlock key to use the Complete Edition. **Download it from the BOOTH purchase page.**

→ [Coming from 2.x (migrating to 3.0)](/en/guide/from-2x)
:::

Not sure which edition you need? → [Free vs Complete Edition](/en/guide/editions)
