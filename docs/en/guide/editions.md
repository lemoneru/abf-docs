# Free vs Complete Edition

The main differences are how many BlendShapes you can fix and which extra features you can use.

The free edition can repair your avatar too. Try it with your expression edits first; you can easily [upgrade to the paid Complete Edition](/en/guide/unlock-key) afterward.

## What the free edition can do

Installing Avatar Blink Fix gives you the free edition.
It can repair `vrc.blink`, a BlendShape commonly used for regular blinking.

→ [Installation](/en/guide/install) ／ [Auto Fix steps](/en/guide/auto-fix)

## What the Complete Edition adds

Go for the paid edition if you want to:

- Fix MMD BlendShapes too
- Fix face-tracking eye-close BlendShapes too
- Fix winks, smiling eyes, and other eye-closing BlendShapes all at once
- Use [Bake Mode](/en/guide/bake) when expression animations conflict with the fix
- Use fine-tune mode, or [merge blinking into expression animations](/en/guide/animation) (extra feature)

::: tip Some avatars have no free-edition target
The free edition auto-selects a commonly used blink BlendShape name (`vrc.blink`, `eye_close`, etc.). Some avatars don't have a BlendShape with such a name, so the free edition can't find a target on them.
Even then, the Complete Edition can fix any BlendShape (and on supported avatars, the preset picks them for you).
:::

## Do I need the paid edition?

Try the free edition first.
If everything looks fine in-game after the fix, **there's no need to upgrade**.

If you have not purchased it yet, get the Complete Edition from the [Avatar Blink Fix page on BOOTH](https://lemoneru.booth.pm/items/7074770) when you want to fix more.

Already purchased? Download the unlock key from BOOTH and import it into a project once. See [Upgrade to the Complete Edition](/en/guide/unlock-key) for the steps.
After that, every project on the same PC runs as the Complete Edition.

- No reinstalling the tool, no recreating projects
- No re-import needed after updates either

2.x owners can use 3.0 free of charge → [How to update from 2.x](/en/guide/from-2x)
