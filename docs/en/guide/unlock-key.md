# Upgrade to the Complete Edition

If you have purchased Avatar Blink Fix, import the unlock key once to use the Complete Edition.

## Start with these three steps

1. Open your [BOOTH Library](https://accounts.booth.pm/library) and download the **latest unlock key** for Avatar Blink Fix
2. Open `AvatarBlinkFix_UnlockKey.unitypackage` and import it into Unity
3. When "Complete Edition Unlocked" appears, you are done

::: tip Other projects
On the same PC, you normally do not need to import the key again. Other projects will also run as the Complete Edition.
:::

## What is the unlock key?

It is a small `.unitypackage` that enables the features you purchased.

- Install the tool itself through [VCC / ALCOM](/en/add)
- Download the unlock key separately from BOOTH, then import it into Unity
- If you purchased 2.x, you still need the 3.0 unlock key. There is no additional charge
- The key is for the purchaser only. Do not share or redistribute it

If you are updating from 2.x, also see [Coming from 2.x](/en/guide/from-2x).

## If it still says Trial Edition

Download the latest unlock key from your BOOTH Library and import it again. The old key will be overwritten.

**Keys downloaded before August 24, 2026 no longer work.** Please use the latest one.

Even if you delete the unlock-key asset from the project, the Complete Edition normally remains active on the same PC.

## Returning to the Trial Edition

In Unity's top menu, open **Tools → Avatar Blink Fix**, then click "Return to Trial Edition." If the project still contains the unlock-key asset, the tool will ask before deleting it as well.

::: tip If you set up an avatar in the Trial Edition
After upgrading, click "Reload Expression" in the Inspector to set up the Complete Edition's fix targets. Forgetting to do this will not damage the avatar.
:::
